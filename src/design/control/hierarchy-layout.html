1.1 Base Layer Group (Z: 0–100)
子层级Z-Index用途
Tile Layerz: 0瓦片底图（卫星图、街道图、暗色底图）
Image / Rasterz: 10–50天气雷达、红外遥感、影像叠层
1.2 Data Visualization Group (Z: 101–500)
子层级Z-Index几何维度示例
Polygon / Choroplethz: 101–200面行政区划、填充图、蜂窝热力
Line / Path / Arcz: 201–300线路线、流向弧线、轨迹
Marker / Bubblez: 301–400点气泡图、聚合点、业务 Marker
Labelz: 401–500文本随 Marker 的文字标注

原则：面 → 线 → 点 → 文本，小要素总在大要素之上，保证视觉可读性。

1.3 Interaction Group (Z: 501–900)
子层级Z-Index说明
Highlight / Activez: 501–700选中/悬停要素，置于同类数据之上
Popupz: 701–800锚定坐标的信息窗
Tooltipz: 801–900紧贴鼠标/要素的即时提示
1.4 UI Shell Group (Z: 1000+)
子层级Z-Index说明
Sidebar / TopBarz: 1000–1099固定面板：侧边栏、顶栏
Floating Controlsz: 1100–1199悬浮控件：缩放、定位、图例
Drawer / Modalz: 1200+全屏遮罩、滑出抽屉
