6. 交互行为 (Interaction)

Hover Highlight

鼠标移入某项，地图对应要素高亮，非对应要素置灰 (dimmed opacity: 0.35)

onHover(index: number)

Toggle Visibility

点击图例项，切换该类要素在地图上的可见性（dimmed 态表示已隐藏）

onToggle(index: number)

Range Brush

连续型图例支持拖动双柄，动态筛选展示的数据范围

onBrush([min, max])

7. Schema 接口速查

LegendSchema Union Type
type LegendSchema =
  | LegendCategoriesSchema   // 定性: 色块 + 标签
  | LegendRampSchema          // 连续/分级: 渐变条
  | LegendDivergingSchema     // 发散: 双极渐变
  | LegendThresholdSchema     // 阈值: [A, B) 区间
  | LegendSizeSchema          // 比例: 大小圆
  | LegendLineWidthSchema     // 线宽: 粗细线段
  | LegendProportionSchema    // 比例: [min, max] 区间圆
  | LegendIconSchema          // 图标: URL 图片 + 标签

interface LegendInteractionCallbacks {
  onHover?:  (index: number) => void
  onToggle?: (index: number) => void
  onBrush?:  (range: [number, number]) => void
}
