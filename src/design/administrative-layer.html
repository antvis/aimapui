行政区划可视化图层

Administrative Layer Interaction Design — 非下钻与下钻模式的视觉呈现与交互逻辑规范

1. 概述

Overview

本规范定义行政区划地图在"非下钻模式"与"下钻模式"下的视觉呈现与交互逻辑。通过标准化的反馈机制，确保用户在不同层级的数据探索中保持清晰的地理感知。

2. 非下钻模式

Macro View

主要用于宏观数据的快速浏览，不涉及地理层级的跳转，侧重于全局对比。

视觉表现 Visual
  • 全局热力：基于最高行政级别进行色阶填充
  • 悬浮即得：悬停显示 Tooltip，边界高亮 1px solid white
  • 静态标签：仅显示核心城市名称，避免视觉拥堵
交互行为 Interaction
  • 单点选定：阴影加深 + 2px 描边，侧边栏联动
  • 平移缩放：支持当前层级内自由平移与有限缩放

3. 下钻模式

Micro View

用于深度探索特定区域。通过层级切换，将视觉中心由宏观切换至微观（省 → 市 → 区）。

视觉表现 Visual
  • 焦点隔离：非焦点区域透明度降至 10-20%，形成掩膜
  • 层级渐进：地图精细度提升，显示更细碎行政边界
  • 面包屑导航：顶部路径 中国 > 广东省 > 深圳市
交互行为 Interaction
  • 双击下钻：双击行政区或点击下钻图标进入下一级
  • 转场动画：中心扩充缩放动画 (Zoom-in Transition)
  • 动态图例：Min/Max 根据当前层级自动重新计算
