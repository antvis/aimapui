# 地图聚合图 (Marker Clustering) 设计规范

本规范定义了在大规模地理数据展示时，点要素聚合的视觉表现与交互逻辑，旨在通过科学的分级与清晰的交互，提升复杂地理数据的可读性与系统性能。

---

## 1. 视觉分级系统 (Visual Grading)

聚合点根据其包含的原始要素数量，采用不同的尺寸、色彩深度及视觉特效进行区分，确保用户能直观感知区域数据密度。

| 等级 | 要素数量 | 尺寸 (Diameter) | 视觉样式 | 文字规范 |
| :--- | :--- | :--- | :--- | :--- |
| **小规模** | 2 - 99 | 32px | `bg-primary/20` 外圈 + `bg-primary` 实心内圈 | 白色 `font-label-sm` |
| **中规模** | 100 - 999 | 40px | `bg-primary/30` 容器 + 2px `border-white/50` 半透明边框 | 白色 `font-label-md` 粗体 |
| **大规模** | 1000+ | 48px | `bg-primary` 渐变至深色 + 强烈脉冲光晕 (Pulse) + `shadow-lg` | 白色 `font-headline-sm` |

## 2. 核心技术参数 (Logic & Thresholds)

为了保证渲染效率与视觉平衡，聚合逻辑遵循以下参数设定：

*   **网格大小 (Grid Size)**: `60px`。在此像素半径内的点要素将执行聚合逻辑。
*   **最小聚合阈值 (Min Cluster Size)**: `2 pts`。至少两个点重合或极近时才形成聚合点。
*   **动画时长 (Animation)**: `300ms`。聚合与离散过程需配合缩放与透明度淡入淡出。
*   **插值函数 (Easing)**: `cubic-bezier(0.4, 0, 0.2, 1)`。

---

## 3. 交互行为规范 (Interaction States)

### 3.1 悬停探索 (Hover Exploration)
*   **视觉反馈**: 聚合点轻微放大 (`scale-110`)。
*   **数据浮窗 (Tooltip)**: 显示该聚合点所包含的要素总数及核心业务摘要（如：*包含 1,245 个物流站点*）。

### 3.2 点击缩放 (Click to Zoom)
*   **默认行为**: 地图视口自动缩放并定位至包含该聚合点内所有子要素的最小边界范围 (`FitBounds`)。
*   **跳转逻辑**: 视口插值至下一个能够使聚合点完全离散的整数缩放级别。

### 3.3 蜘蛛布局 (Spiderfier)
当用户已缩放至最大级别，但多个要素仍因坐标相同或极近而重叠时触发：
*   **视觉表现**: 从中心坐标点延伸出细实线 (`stroke-outline-variant/50`) 连接至具体的 Marker。
*   **展开方式**: 螺旋状或圆形展开，确保每个要素独立可见且可点击。

## 4. 动效与动感 (Motion & Logic Triggers)

*   **数字更新**: 聚合数量增加或减少时，数字采用平滑的垂直平移切换动效。
*   **边界吸附**: 聚合点在移动时应保持平滑的轨迹合并，避免视觉上的闪烁。
