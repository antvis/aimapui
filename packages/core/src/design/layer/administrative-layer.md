# 行政区划可视化图层交互设计规范 (Administrative Layer Interaction Specs)

## 1. 概述 (Overview)
本规范旨在定义行政区划地图在"非下钻模式"与"下钻模式"下的视觉呈现与交互逻辑。通过标准化的反馈机制，确保用户在不同层级的数据探索中保持清晰的地理感知。

## 2. 非下钻模式 (Non-Drill Mode)
**定义**：主要用于宏观数据的快速浏览，不涉及地理层级的跳转，侧重于全局对比。

### A. 视觉表现
*   **全局热力 (Global Heatmap)**：基于当前选定的最高行政级别（如全国/全省）进行色阶填充。
*   **悬浮即得 (Hover-to-Peek)**：鼠标悬停在区域上时，仅显示简略信息浮窗（Tooltip），区域边界高亮（1px Solid White）。
*   **静态标签**：仅显示核心城市的名称，避免视觉拥堵。

### B. 交互行为
*   **单点选定**：点击某一区域时，该区域进入"选定态"（阴影加深 + 2px 描边），侧边栏联动更新该区域的详细统计数据。
*   **平移与缩放**：地图支持在当前层级内自由平移和有限范围的缩放。

---

## 3. 下钻模式 (Drill-down Mode)
**定义**：用于深度探索特定区域。通过层级切换，将视觉中心由宏观切换至微观（如：省 -> 市 -> 区）。

### A. 视觉表现
*   **焦点隔离 (Focus Isolation)**：下钻后，非焦点区域（父级余部）透明度降低至 10-20%，形成视觉掩膜。
*   **层级渐进 (Layer Progression)**：随着层级加深，地图精细度提升，显示更细碎的行政边界（如乡镇/街道网格）。
*   **面包屑导航 (Breadcrumbs)**：顶部显示清晰的路径（例如：中国 > 广东省 > 深圳市），支持快速回溯。

### B. 交互行为
*   **双击/点击图标下钻**：通过双击行政区或点击区域上的"下钻图标"进入下一级视图。
*   **转场动画**：采用"中心扩充"缩放动画（Zoom-in Transition），保持视觉连续性。
*   **动态图例**：图例的范围值（Min/Max）根据当前层级的数据分布自动重新计算（Auto-scaling）。

---

## 4. 模式切换机制 (Switching Mechanism)
*   **控件位置**：地图右上角控制台。
*   **逻辑**：
    *   **锁定模式 (Lock)**：默认非下钻，点击仅选中。
    *   **深度模式 (Explore)**：激活下钻逻辑，允许层级穿透。

## 5. 视觉规范对照 (Visual Mapping)

| 元素 | 非下钻 (Macro) | 下钻 (Micro) |
| :--- | :--- | :--- |
| **背景色** | Aether Surface-Dim | Aether Surface-Bright |
| **边界线** | 2px 实线 (省界) | 1px 虚线 (区界) |
| **标签规模** | 大字号、粗体 | 中字号、常规 |
| **数据卡片** | 全局排名 | 区域详情 + 趋势图 |
