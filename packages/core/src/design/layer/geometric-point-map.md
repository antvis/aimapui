# 地图几何点位 (Geometric Point Map) 设计规范

本规范定义了除标准 Marker 外的几何形状点位（圆、三角、六边形、星形等）的视觉表现与数据映射标准，旨在为多维数据可视化提供丰富的视觉编码手段。

---

## 1. 核心几何形态 (Shape Definitions)

根据业务语义与区分度，系统提供以下基础几何体：

### 1.1 圆形 (Circle) - [Default]
*   **语义**: 连续、平衡、中性。
*   **场景**: 默认散点、人流密度、一般性业务点。
*   **视觉特征**: 完美对称，视觉重心最稳固，适合重叠显示。

### 1.2 三角形 (Triangle)
*   **语义**: 警告、方向、不稳定性。
*   **场景**: 风险点、上行/下行趋势、交通监控。
*   **视觉特征**: 具有强烈的指向性（尖角对齐），适合展示具有方向属性的数据。

### 1.3 六边形 (Hexagon)
*   **语义**: 技术感、结构化、单元。
*   **场景**: 基站覆盖、网格化指标、能源节点。
*   **视觉特征**: 能够无缝拼接（蜂窝），空间利用率高。

### 1.4 正方形/菱形 (Square/Diamond)
*   **语义**: 稳固、静态、人工设施。
*   **场景**: 建筑基点、固定仓储、行政机构。

---

## 2. 视觉编码规范 (Visual Encoding)

### 2.1 形状与尺寸映射
*   **形状作为分类 (Categorical)**: 不同形状代表不同的业务类型（如：圆形-仓库，三角形-车辆）。
*   **尺寸与指标关联**: 几何体的外接圆直径随权重值变化。
    *   **MIN**: 8px。
    *   **MAX**: 48px。

### 2.2 样式处理
*   **填充 (Fill)**: `bg-primary/30` 到 `bg-primary` 的渐变。
*   **描边 (Stroke)**: 1px 白色或反色描边，确保在复杂底图上的轮廓清晰。
*   **发光 (Glow)**: 核心要素开启外发光效果，增强视觉优先级。

---

## 3. 交互与状态 (Interactions)

### 3.1 悬停反馈 (Hover)
*   **视觉变化**: 形状等比放大 1.2 倍，填充不透明度提升。
*   **高亮**: 边缘出现 2px 的品牌色高亮环。

### 3.2 选中状态 (Selected)
*   **视觉反馈**: 增加呼吸感波纹 (`animate-pulse`)，形状内部填充色彩反转。

---

## 4. WebGL 渲染性能 (Performance)

*   **SDF 渲染**: 所有的几何形状均通过 WebGL SDF (Signed Distance Fields) 技术绘制。
*   **优势**: 
    *   **边缘锐利**: 缩放过程中无锯齿。
    *   **瞬间切换**: 毫秒级实现形状、颜色、尺寸的动态变换。
*   **碰撞避让**: 针对不同形状的包围盒 (Bounding Box) 执行 R-Tree 实时避让逻辑。
