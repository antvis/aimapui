◆ CPS Raster Module v1.0.0

栅格数据可视化

GeoTIFF / Cloud Optimized GeoTIFF 的视觉表现、波段映射与数据交互标准，为遥感分析、气象监测提供精确的地理影像表达。

01 · 栅格渲染模式
Single Band
灰度图 · DEM 高程
灰度图 (Grayscale)
单一连续变量，surface-container → on-surface 明度映射。默认 Bilinear 插值。
Pseudo Color
伪彩色 · 地形着色
伪彩色映射
单波段数值通过 Scale 映射至预设色带，支持 Terrain / Thermal / NDVI 等。
Multi-band
真彩色 · 卫星影像
真彩色/多波段合成
RGB 通道指定波段索引。假彩色使用 NIR/SWIR 突出特定地物。
