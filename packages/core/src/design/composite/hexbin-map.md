# 地图蜂窝热力图 (Hexbin Map) 设计规范

本规范定义了六边形网格化空间统计图层的视觉表现与交互逻辑。蜂窝热力图旨在将海量离散点数据聚合为规则的几何单元，消除行政区划带来的视觉偏差，提供更科学的密度分布展示。

---

## 1. 基础几何定义 (Geometry Definitions)

### 1.1 六边形尺寸 (Radius)
*   **自适应缩放**: 蜂窝半径应随缩放级别动态调整。
*   **默认尺寸**: 屏幕空间下半径为 `20px - 40px`。
*   **计算逻辑**: 确保在当前视口下既能体现趋势，又不至于产生严重的视觉破碎感。

### 1.2 2D 平面模式 (2D Flat)
*   **样式**: 完美的正六边形，无描边或 0.5px 极细描边。
*   **间距 (Gap)**: 蜂窝单元之间保持 `1px` 的物理间距，增强几何阵列的纯粹感与现代感。
*   **混合模式**: 默认 `normal`，在复杂底图上可使用 `multiply` (浅色) 或 `screen` (深色)。

---

## 2. 视觉分级与映射 (Visual Mapping)

### 2.1 色彩映射 (Color Ramp)
采用 **Cartographic Precision System** 的单色或发散色阶。
*   **低权重**: `bg-primary/10` 或浅色。
*   **中权重**: `bg-primary/50`。
*   **高权重**: `bg-primary` (100% 不透明度)。
*   **不透明度**: 整体图层建议设置 `opacity-80`，确保底图路网特征可见。

### 2.2 3D 挤压模式 (3D Extrusion)
用于在二维地图上引入第三维度（高度）来强化权重对比。
*   **高度映射**: 高度 ($H$) 随聚合要素数量或指标值线性/对数增长。
*   **侧面渲染**: 侧面颜色比顶面深 `15% - 20%`，以增强立体感与深度。
*   **光照效果**: 模拟 45 度固定光源，柱体带微弱投影 `shadow-md`。

---

## 3. 交互行为 (Interaction)

### 3.1 悬停探索 (Hover)
*   **视觉反馈**: 
    *   **2D**: 该六边形边缘加粗至 2px，颜色切换为 `secondary` 强调色。
    *   **3D**: 选中的立柱整体高亮，并增加发光边缘。
*   **轻提示 (Tooltip)**: 显示该区域的聚合总数、核心指标百分比及区域范围描述。

### 3.2 点击交互 (Click)
*   **逻辑**: 地图视口下钻（Zoom In）至该六边形所覆盖的地理范围，并将蜂窝自动拆解为更小一级的网格或原始 Marker 点。

---

## 4. 动效规范 (Motion)

*   **数据平滑**: 当图层数据更新时，高度变化应带有 `duration-500 ease-out` 的平滑过渡，避免瞬间跳变。
*   **入场动画**: 蜂窝单元从地图中心向外逐一淡入并伴随轻微的缩放效果。
