# 主题与样式

aimapkit 采用 **Material Design 3** 设计体系，内置亮色/暗色主题切换，并提供完整的设计令牌系统。

## 主题切换

### Schema 模式

通过 `theme` 属性设置主题：

```tsx
<Aimap schema={schema} theme="dark" />
```

支持的主题值：

| 值 | 说明 |
|------|------|
| `'light'` | 亮色主题（默认） |
| `'dark'` | 暗色主题 |
| `'system'` | 跟随系统设置 |

### 组件模式

使用 `useTheme` Hook 动态切换：

```tsx
import { Aimap, ZoomControl, useTheme } from '@antv/aimapkit'

function ThemeToggle() {
  const { theme, setTheme, toggleTheme } = useTheme()

  return (
    <button onClick={toggleTheme}>
      当前主题: {theme} (点击切换)
    </button>
  )
}
```

### 底图主题联动

切换 UI 主题时，底图样式可联动切换：

```tsx
import { Aimap, MapThemeControl } from '@antv/aimapkit'

// MapThemeControl 组件提供底图样式选择下拉框
// 自动获取当前底图支持的样式列表
function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <MapThemeControl position="topright" />
    </Aimap>
  )
}
```

## 设计令牌

### 颜色

| 令牌 | 亮色值 | 暗色值 | 用途 |
|------|--------|--------|------|
| `--color-primary` | `#3B82F6` | `#60A5FA` | 主色 |
| `--color-surface` | `#FFFFFF` | `#1E293B` | 表面背景 |
| `--color-on-primary` | `#FFFFFF` | `#FFFFFF` | 主色上的文字 |
| `--color-on-surface` | `#1E293B` | `#E2E8F0` | 表面上的文字 |
| `--color-success` | `#10B981` | `#34D399` | 成功色 |
| `--color-warning` | `#F59E0B` | `#FBBF24` | 警告色 |
| `--color-error` | `#EF4444` | `#F87171` | 错误色 |

### 间距

| 令牌 | 值 | 用途 |
|------|------|------|
| `--space-xs` | `4px` | 极小间距 |
| `--space-sm` | `8px` | 小间距 |
| `--space-md` | `12px` | 中间距 |
| `--space-lg` | `16px` | 大间距 |
| `--space-xl` | `24px` | 超大间距 |

### 圆角

| 令牌 | 值 | 用途 |
|------|------|------|
| `--radius-sm` | `4px` | 小圆角 |
| `--radius-md` | `8px` | 中圆角 |
| `--radius-lg` | `12px` | 大圆角 |
| `--radius-full` | `9999px` | 全圆角 |

## 玻璃拟态控件

aimapkit 的控件采用 Material Design 3 玻璃拟态（Glassmorphism）风格：

- 半透明背景 + `backdrop-blur`
- 细微边框 + 柔和阴影
- 亮色/暗色主题自动适配

```css
/* 控件默认样式 */
.l7-control {
  background: rgba(255, 255, 255, 0.8);
  backdrop-filter: blur(8px);
  border: 1px solid rgba(0, 0, 0, 0.08);
  border-radius: 12px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
}

/* 暗色主题 */
[data-theme="dark"] .l7-control {
  background: rgba(30, 41, 59, 0.8);
  border-color: rgba(255, 255, 255, 0.08);
}
```

## 地图色板

aimapkit 内置多种地图可视化专用色板：

### 顺序色板 (Sequential)

适用于单一指标的高低对比：

```tsx
const sequentialColors = [
  '#DBEAFE', '#93C5FD', '#60A5FA', '#3B82F6', '#2563EB'
]
```

### 发散色板 (Diverging)

适用于围绕中性参考点的偏离：

```tsx
const divergingColors = [
  '#EF4444', '#FCA5A5', '#F3F4F6', '#93C5FD', '#3B82F6'
]
```

### 分类色板 (Categorical)

适用于定性分类数据：

```tsx
const categoricalColors = [
  '#3B82F6', '#10B981', '#F59E0B', '#EF4444', '#8B5CF6', '#EC4899'
]
```

## 响应式设计

aimapkit 内置响应式断点，自动适配移动端：

```tsx
const schema = {
  responsive: {
    breakpoint: 768,  // 移动端断点
    mobile: {
      controls: {
        position: 'bottomcenter',
        scale: 0.85,
        hide: ['mouseLocation', 'exportImage']
      },
      legends: {
        compact: true,
        position: 'bottom'
      }
    }
  }
}
```
