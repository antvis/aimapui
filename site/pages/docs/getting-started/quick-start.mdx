# 快速开始

本指南将帮助你在 5 分钟内创建第一个地图可视化应用。

## 准备工作

### 1. 获取高德地图 Key

aimapui 使用高德地图作为底图,你需要先申请高德地图 Key:

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册账号并登录
3. 进入控制台,创建应用
4. 添加 Key,选择"Web 服务"类型
5. 复制生成的 Key

### 2. 创建项目

```bash
# 使用 Create React App
npx create-react-app my-map-app --template typescript
cd my-map-app

# 或使用 Vite
npm create vite@latest my-map-app -- --template react-ts
cd my-map-app
```

### 3. 安装依赖

```bash
npm install @antv/aimapui @antv/l7 @antv/l7-maps
```

## 第一个地图

创建一个简单的点图层地图:

```tsx
// src/App.tsx
import { Aimap } from '@antv/aimapui'
import '@antv/aimapui/style.css'

const schema = {
  map: {
    basemap: 'gaode',
    token: 'YOUR_AMAP_KEY', // 替换为你的高德地图 Key
    center: [116.397428, 39.90923], // 北京天安门
    zoom: 10
  },
  layers: [{
    type: 'point',
    source: [
      { lng: 116.397, lat: 39.909, name: '点1', value: 100 },
      { lng: 116.398, lat: 39.910, name: '点2', value: 200 },
      { lng: 116.396, lat: 39.908, name: '点3', value: 150 }
    ],
    sourceType: 'json',
    color: '#1890ff',
    size: 12
  }]
}

function App() {
  return (
    <div style={{ width: '100%', height: '100vh' }}>
      <Aimap schema={schema} />
    </div>
  )
}

export default App
```

## 添加交互

让我们添加一个信息窗体,点击点位时显示详细信息:

```tsx
const schema = {
  map: {
    basemap: 'gaode',
    token: 'YOUR_AMAP_KEY',
    center: [116.397428, 39.90923],
    zoom: 10
  },
  layers: [{
    type: 'point',
    source: [
      { lng: 116.397, lat: 39.909, name: '点1', value: 100 },
      { lng: 116.398, lat: 39.910, name: '点2', value: 200 },
      { lng: 116.396, lat: 39.908, name: '点3', value: 150 }
    ],
    sourceType: 'json',
    color: '#1890ff',
    size: 12,
    enablePopup: true,
    popupFields: ['name', 'value']
  }]
}
```

## 添加控件

添加缩放控件和比例尺:

```tsx
const schema = {
  map: {
    basemap: 'gaode',
    token: 'YOUR_AMAP_KEY',
    center: [116.397428, 39.90923],
    zoom: 10
  },
  layers: [{
    type: 'point',
    source: [
      { lng: 116.397, lat: 39.909, name: '点1', value: 100 }
    ],
    sourceType: 'json',
    color: '#1890ff',
    size: 12
  }],
  controls: [
    { type: 'zoom', position: 'topright' },
    { type: 'scale', position: 'bottomleft' }
  ]
}
```

## 使用事件

监听地图事件:

```tsx
import { Aimap } from '@antv/aimapui'
import type { Scene } from '@antv/l7'

function App() {
  const handleSceneReady = (scene: Scene) => {
    console.log('场景就绪', scene)
    
    // 监听点击事件
    scene.on('click', (e) => {
      console.log('点击位置', e.lnglat)
    })
  }

  return (
    <div style={{ width: '100%', height: '100vh' }}>
      <Aimap 
        schema={schema} 
        onSceneReady={handleSceneReady}
      />
    </div>
  )
}
```
