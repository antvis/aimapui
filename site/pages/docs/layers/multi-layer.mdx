# 多图层组合

实际项目中，单一图层往往不足以表达完整的数据故事。aimapkit 支持在 Schema 中声明多个图层，并在组件模式中嵌套多个图层组件。

## Schema 多图层

```tsx
const schema = {
  map: { basemap: 'gaode', style: 'dark', center: [116.397, 39.909], zoom: 5 },
  layers: [
    // 底层：区域填充
    {
      type: 'polygon',
      source: regionData,
      sourceType: 'geojson',
      colorField: 'gdp',
      colorValues: ['#1E3A8A', '#3B82F6', '#93C5FD'],
      style: { opacity: 0.6 },
      zIndex: 0
    },
    // 中层：飞线动画
    {
      type: 'line',
      source: flowData,
      sourceType: 'json',
      sourceConfig: { x: 'fromLng', y: 'fromLat', x1: 'toLng', y1: 'toLat' },
      shape: 'arc',
      color: '#F59E0B',
      size: 1.5,
      animate: { enable: true, duration: 4, trailLength: 1 },
      zIndex: 1
    },
    // 顶层：点位标记
    {
      type: 'point',
      source: cityData,
      sourceType: 'json',
      sizeField: 'population',
      sizeValues: [6, 20],
      color: '#FBBF24',
      zIndex: 2
    }
  ]
}
```

## 组件多图层

```tsx
import { Aimap, PolygonLayer, LineLayer, PointLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', style: 'dark', center: [116.397, 39.909], zoom: 5 }}>
      <PolygonLayer source={regionData} sourceType="geojson" colorField="gdp" colorValues={['#1E3A8A', '#3B82F6', '#93C5FD']} style={{ opacity: 0.6 }} />
      <LineLayer source={flowData} sourceType="json" sourceConfig={{ x: 'fromLng', y: 'fromLat', x1: 'toLng', y1: 'toLat' }} shape="arc" color="#F59E0B" size={1.5} animate={{ enable: true, duration: 4, trailLength: 1 }} />
      <PointLayer source={cityData} sourceType="json" sizeField="population" sizeValues={[6, 20]} color="#FBBF24" />
    </Aimap>
  )
}
```

## 图层顺序

- Schema `layers` 数组中，**后面的图层渲染在上层**
- 组件模式中，**后面的子组件渲染在上层**
- 可用 `zIndex` 显式控制层级

## 图层显隐控制

```tsx
// Schema 模式
{ type: 'point', source: data, visible: false, ... }

// 组件模式
<PointLayer visible={showPoints} ... />
```

## 图层联动

```tsx
function App() {
  const [selected, setSelected] = useState(null)

  return (
    <Aimap map={mapConfig}>
      <PolygonLayer
        source={regions}
        onClick={(e) => setSelected(e.feature.properties.id)}
      />
      <PointLayer
        source={highlightPoints}
        visible={!!selected}
      />
    </Aimap>
  )
}
```
