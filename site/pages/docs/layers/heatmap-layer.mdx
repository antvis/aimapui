# 热力图层 (HeatmapLayer)

热力图层用于展示数据的密度分布，支持经典网格热力和蜂窝聚合热力两种模式。

## Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', style: 'dark', center: [116.397, 39.909], zoom: 11 },
  layers: [{
    type: 'heatmap',
    source: pointsData,
    sourceType: 'json',
    shape: 'heatmap',
    sizeField: 'value',
    color: ['#0d0366', '#3e0f8f', '#b93289', '#f58c6c', '#fbdd7e', '#fffff0']
  }]
}
```

## Shape 类型

| shape 值 | 说明 | 适用场景 |
|----------|------|---------|
| `heatmap` | 经典网格热力（默认） | 通用密度分布 |
| `hexagon` | 蜂窝热力 | 规则六边形聚合 |

## 经典热力

```tsx
{
  type: 'heatmap',
  source: data,
  sourceType: 'json',
  shape: 'heatmap',
  sizeField: 'value',
  color: ['#0d0366', '#3e0f8f', '#b93289', '#f58c6c', '#fbdd7e', '#fffff0']
}
```

## 蜂窝热力

```tsx
{
  type: 'heatmap',
  source: data,
  sourceType: 'json',
  shape: 'hexagon',
  sizeField: 'value',
  colorField: 'count',
  colorValues: ['#DBEAFE', '#60A5FA', '#2563EB', '#1E3A8A'],
  style: { coverage: 0.9, opacity: 0.8 }
}
```

## 组件用法

```tsx
import { Aimap, HeatmapLayer } from '@antv/aimapui'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', style: 'dark', center: [116.397, 39.909], zoom: 11 }}>
      <HeatmapLayer
        source={pointsData}
        sourceType="json"
        shape="heatmap"
        sizeField="value"
        color={['#0d0366', '#3e0f8f', '#b93289', '#f58c6c', '#fbdd7e', '#fffff0']}
      />
    </Aimap>
  )
}
```

## 热力颜色方案

| 场景 | 推荐配色 | 说明 |
|------|---------|------|
| 经典热力 | `['#0d0366', '#b93289', '#f58c6c', '#fffff0']` | 紫到暖，密度由低到高 |
| 冷色热力 | `['#eff6ff', '#3b82f6', '#1e3a8a']` | 篮球色系 |
| 暖色热力 | `['#fef3c7', '#f59e0b', '#b45309']` | 黄到棕 |
| 暗底热力 | `['#000000', '#7c3aed', '#f97316', '#fbbf24']` | 适合暗色底图 |
