# 面图层 (PolygonLayer)

面图层用于展示区域数据，支持填充、描边、3D挤出和文字标注。

## Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', center: [116.37, 39.84], zoom: 10.3 },
  layers: [{
    type: 'polygon',
    source: geojsonData,
    sourceType: 'geojson',
    colorField: 'value',
    colorValues: ['#DBEAFE', '#93C5FD', '#60A5FA', '#3B82F6', '#2563EB'],
    style: { opacity: 0.8 },
    active: { color: '#ffffff' },
    select: { color: '#0f172a' }
  }]
}
```

## 组件用法

```tsx
import { Aimap, PolygonLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.37, 39.84], zoom: 10.3 }}>
      <PolygonLayer
        source={geojsonData}
        sourceType="geojson"
        colorField="value"
        colorValues={['#DBEAFE', '#93C5FD', '#60A5FA', '#3B82F6', '#2563EB']}
        style={{ opacity: 0.8 }}
        active={{ color: '#ffffff' }}
        select={{ color: '#0f172a' }}
        onClick={(e) => console.log('选中区域:', e.feature)}
      />
    </Aimap>
  )
}
```

## 3D 挤出

```tsx
{
  type: 'polygon',
  source: buildingData,
  sourceType: 'geojson',
  sizeField: 'height',
  sizeValues: [0, 500],
  color: '#3B82F6',
  style: { opacity: 0.8 }
}
```

## 填充 + 描边 + 文字标注

多图层叠加实现完整的面图层效果：

```tsx
layers: [
  // 填充面
  { type: 'polygon', source: regions, sourceType: 'geojson', colorField: 'value', colorValues: [...] },
  // 描边线
  { type: 'line', source: regions, sourceType: 'geojson', color: 'rgba(255,255,255,0.3)', size: 0.5 },
  // 文字标注
  { type: 'point', source: labels, sourceType: 'json', shapeField: 'name', shapeValues: 'text', size: 11, color: '#0f172a' }
]
```

## 颜色映射模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| Sequential (顺序) | 单色由浅到深 | 人口密度、温度 |
| Diverging (发散) | 从负值到正值 | 增速、温差偏差 |
| Categorical (分类) | 互补色 | 行政类型、土地用途 |
