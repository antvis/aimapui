# 栅格与图片图层

## 栅格图层 (RasterLayer)

栅格图层用于加载和渲染栅格瓦片或影像数据。

### Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 6 },
  layers: [{
    type: 'raster',
    source: 'https://tiles.example.com/{z}/{x}/{y}.png',
    sourceType: 'raster',
    minZoom: 0,
    maxZoom: 18
  }]
}
```

### 组件用法

```tsx
import { Aimap, RasterLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 6 }}>
      <RasterLayer
        source="https://tiles.example.com/{z}/{x}/{y}.png"
        sourceType="raster"
        minZoom={0}
        maxZoom={18}
      />
    </Aimap>
  )
}
```

## 图片图层 (ImageLayer)

图片图层用于在地图上叠加单张图片，通过经纬度范围定位。

### Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 10 },
  layers: [{
    type: 'image',
    source: {
      x: 116.2, y: 39.7,
      x1: 116.6, y1: 40.1,
      image: '/overlay.png'
    },
    sourceType: 'image',
    style: { opacity: 0.7 }
  }]
}
```

### 组件用法

```tsx
import { Aimap, ImageLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <ImageLayer
        source={{ x: 116.2, y: 39.7, x1: 116.6, y1: 40.1, image: '/overlay.png' }}
        sourceType="image"
        style={{ opacity: 0.7 }}
      />
    </Aimap>
  )
}
```
