# 点图层 (PointLayer)

点图层是最常用的图层类型，用于在地图上展示离散的点位数据，支持散点、3D柱状、文本标注等多种形态。

## Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 10 },
  layers: [{
    type: 'point',
    source: [
      { lng: 116.397, lat: 39.909, name: '北京', value: 100 },
      { lng: 121.473, lat: 31.230, name: '上海', value: 200 }
    ],
    sourceType: 'json',
    color: '#3B82F6',
    size: 12
  }]
}
```

## 组件用法

```tsx
import { Aimap, PointLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <PointLayer
        source={data}
        sourceType="json"
        color="#3B82F6"
        size={12}
        onClick={(e) => console.log('点击:', e.feature)}
      />
    </Aimap>
  )
}
```

## Shape 类型

| shape 值 | 说明 | 适用场景 |
|----------|------|---------|
| `circle` | 圆形（默认） | 散点图、定位标记 |
| `circleStroke` | 描边圆 | 需要边框的点位 |
| `square` | 正方形 | 分类标记 |
| `diamond` | 菱形 | 特殊分类 |
| `triangle` | 三角形 | 方向指示 |
| `cylinder` | 3D 柱体 | 数据柱状图 |
| `text` | 文本标注 | 地名、标签 |

## 数据驱动颜色

```tsx
{
  type: 'point',
  source: data,
  sourceType: 'json',
  colorField: 'category',        // 按字段映射
  colorValues: ['#3B82F6', '#10B981', '#F59E0B', '#EF4444']
}
```

## 数据驱动大小

```tsx
{
  type: 'point',
  source: data,
  sourceType: 'json',
  sizeField: 'value',
  sizeValues: [6, 30]  // [最小, 最大]
}
```

## 3D 柱状图

```tsx
{
  type: 'point',
  source: data,
  sourceType: 'json',
  shape: 'cylinder',
  size: 10,
  colorField: 'value',
  colorValues: ['#93C5FD', '#3B82F6', '#1D4ED8']
}
```

## 文本标注

```tsx
{
  type: 'point',
  source: labels,
  sourceType: 'json',
  sourceConfig: { x: 'lng', y: 'lat' },
  shapeField: 'name',
  shapeValues: 'text',
  color: '#0f172a',
  size: 12,
  style: { stroke: '#ffffff', strokeWidth: 2, textAllowOverlap: false }
}
```

## 交互

```tsx
<PointLayer
  source={data}
  sourceType="json"
  color="#3B82F6"
  size={12}
  active={{ color: '#F59E0B' }}    // 悬停高亮
  select={{ color: '#EF4444' }}     // 点击选中
  onClick={(e) => console.log(e.feature)}
  onMouseEnter={(e) => console.log('enter')}
  onMouseLeave={(e) => console.log('leave')}
/>
```
