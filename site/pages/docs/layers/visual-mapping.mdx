# 视觉映射

视觉映射是将数据字段映射到视觉通道（颜色、大小、形状）的核心机制，aimapkit 在 Schema 和组件模式中均提供一致的计算可视化语义。

## 三种视觉通道

### 1. 颜色映射 (Color)

固定颜色：

```tsx
color: '#3B82F6'
```

数据驱动颜色（分类）：

```tsx
colorField: 'category',
colorValues: ['#3B82F6', '#10B981', '#F59E0B', '#EF4444']
```

数据驱动颜色（连续）：

```tsx
colorField: 'temperature',
colorValues: ['#DBEAFE', '#93C5FD', '#3B82F6', '#1D4ED8', '#1E3A8A']
```

### 2. 大小映射 (Size)

固定大小：

```tsx
size: 12
```

数据驱动大小：

```tsx
sizeField: 'population',
sizeValues: [4, 40]  // [最小值, 最大值] 像素
```

### 3. 形状映射 (Shape)

固定形状：

```tsx
shape: 'circle'
```

数据驱动形状：

```tsx
shapeField: 'type',
shapeValues: ['circle', 'square', 'diamond']
```

## 内置色板

| 名称 | 色值 | 说明 |
|------|------|------|
| `blue` | `['#DBEAFE', '#3B82F6', '#1E3A8A']` | 蓝色系 |
| `green` | `['#D1FAE5', '#10B981', '#064E3B']` | 绿色系 |
| `red` | `['#FEE2E2', '#EF4444', '#7F1D1D']` | 红色系 |
| `yellow` | `['#FEF3C7', '#F59E0B', '#78350F']` | 黄色系 |
| `spectral` | `['#3B82F6', '#10B981', '#F59E0B', '#EF4444']` | 光谱色 |
| `viridis` | `['#440154', '#31688E', '#35B779', '#FDE725']` | 科学可视化 |

## 组件模式等价写法

```tsx
// Schema 模式
{ colorField: 'value', colorValues: ['#DBEAFE', '#1E3A8A'] }

// 组件模式
<PointLayer colorField="value" colorValues={['#DBEAFE', '#1E3A8A']} />
```

## Scale 配置

```tsx
{
  colorField: 'value',
  colorValues: ['#DBEAFE', '#1E3A8A'],
  scale: {
    value: { type: 'quantize', domain: [0, 100] }  // 等间距分段
  }
}
```

| Scale 类型 | 说明 | 适用场景 |
|-----------|------|---------|
| `linear` | 线性插值（默认） | 连续数值 |
| `quantize` | 等间距分段 | 分级统计 |
| `quantile` | 等数量分段 | 百分位分级 |
| `cat` | 分类映射 | 离散类别 |
| `log` | 对数映射 | 数据跨度大 |
| `pow` | 幂次映射 | 非线性分布 |
