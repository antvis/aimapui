# Popup 弹出框

Popup 是地图上固定位置的富信息弹窗，支持多种尺寸和结构化内容展示。

## 尺寸变体

| 尺寸 | 值 | 宽度 | 适用场景 |
|------|------|------|---------|
| Compact | `compact` | 200px | 简短信息、单行数据 |
| Standard | `standard` | 280px | 常规信息、属性列表 |
| Detailed | `detailed` | 360px | 详细信息、封面图+属性+操作 |

## 结构化内容

Standard 和 Detailed 尺寸支持结构化布局：

```tsx
<Popup
  longitude={116.397}
  latitude={39.909}
  size="standard"
  header="天安门广场"
  attributes={[
    { label: '类型', value: '景点' },
    { label: '评分', value: '4.8' },
    { label: '开放时间', value: '全天' }
  ]}
  actions={[{ label: '导航', onClick: () => {} }]}
  closeButton
/>
```

## Schema 用法

```tsx
const schema = {
  interactions: [
    {
      type: 'popup',
      longitude: 116.397,
      latitude: 39.909,
      content: '<strong>天安门广场</strong><br/>开放时间: 全天',
      size: 'standard',
      closeButton: true
    }
  ]
}
```

## 定位与翻转

Popup 支持 `placement` 属性控制弹出方向，并自动翻转以避免超出视口：

| placement | 说明 |
|-----------|------|
| `auto` | 自动选择最佳方向 |
| `top` | 上方弹出 |
| `bottom` | 下方弹出 |
| `left` | 左侧弹出 |
| `right` | 右侧弹出 |

## 互斥模式

启用 `singleton` 属性，同一地图上同时只显示一个 Popup：

```tsx
<Popup singleton size="compact">
  内容
</Popup>
```

## 玻璃拟态风格

Popup 默认采用 Material Design 3 玻璃拟态（Glassmorphism）风格：

- 半透明背景 + `backdrop-blur`
- 细微边框 + 柔和阴影
- 亮/暗主题自动适配
