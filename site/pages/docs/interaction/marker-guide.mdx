# Marker 标注

Marker 是地图上最直观的位置标注方式，aimapkit 提供了 4 种视觉形态、4 种语义颜色和丰富的交互能力。

## 形态变体

| 变体 | 说明 | 适用场景 |
|------|------|---------|
| `pin` | 经典地图钉 | 地点标记、POI |
| `circle` | 圆形标记 | 等级区分、数量标记 |
| `icon` | 图标标记 | 设施分类、功能定位 |
| `dot` | 简约圆点 | 密集标记、辅助点 |

## 语义颜色

| 颜色 | 值 | 含义 |
|------|------|------|
| Primary | `#3B82F6` | 默认/主要 |
| Success | `#10B981` | 完成/在线/正常 |
| Warning | `#F59E0B` | 警告/待处理 |
| Error | `#EF4444` | 错误/离线/异常 |

## 交互状态

- **默认 (Default)**：正常显示
- **悬停 (Hover)**：放大 120%、阴影加深
- **选中 (Selected)**：脉冲动画 + 高亮描边
- **未激活 (Inactive)**：不透明度 40%

## Schema 用法

```tsx
const schema = {
  interactions: [
    {
      type: 'marker',
      longitude: 116.397,
      latitude: 39.909,
      content: '天安门',
      variant: 'pin',
      color: 'primary'
    },
    {
      type: 'marker',
      longitude: 121.473,
      latitude: 31.230,
      content: '上海',
      variant: 'circle',
      color: 'success',
      draggable: true
    }
  ]
}
```

## 组件用法

```tsx
import { Aimap, Marker } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <Marker
        longitude={116.397}
        latitude={39.909}
        variant="pin"
        color="primary"
      >
        天安门
      </Marker>
      <Marker
        longitude={121.473}
        latitude={31.230}
        variant="circle"
        color="success"
        draggable
        onDragEnd={(lnglat) => console.log('新位置:', lnglat)}
      >
        上海
      </Marker>
    </Aimap>
  )
}
```

## 缩放自适应

Marker 支持根据地图缩放级别自动调整显示策略：

| 缩放范围 | 显示策略 |
|---------|---------|
| 低缩放（< 6） | 仅显示圆点（dot） |
| 中缩放（6-12） | 显示图标（icon） |
| 高缩放（> 12） | 显示图标 + 文字标签 |

## 拖拽

启用 `draggable` 属性后，用户可以拖拽 Marker 并获取新位置：

```tsx
<Marker
  longitude={116.397}
  latitude={39.909}
  draggable
  onDragStart={() => console.log('开始拖拽')}
  onDragging={(lnglat) => console.log('拖拽中:', lnglat)}
  onDragEnd={(lnglat) => console.log('拖拽结束:', lnglat)}
>
  可拖拽标记
</Marker>
```
