# 交互总览

aimapkit 提供了丰富的地图交互能力，包括图层交互、标注交互、事件系统三大类。

## 交互类型一览

| 类型 | 说明 | 主要组件 |
|------|------|---------|
| 图层交互 | 鼠标悬停高亮、点击选中、信息窗体 | `active` / `select` / Popup |
| 标注交互 | 自定义标注点、可拖拽标注 | `Marker` / MarkerSchema |
| 弹窗交互 | 固定位置弹出框、轻量提示 | `Popup` / `Tooltip` |
| 地图事件 | 缩放、移动、点击等地图级别事件 | `onSceneReady` / EventBus |

## Schema 模式 vs 组件模式

### Schema 模式（声明式）

```tsx
const schema = {
  layers: [{
    type: 'point',
    source: data,
    sourceType: 'json',
    color: '#1890ff',
    size: 10,
    active: { color: '#ff4d4f' },       // 悬停高亮
    select: { color: '#52c41a' },        // 点击选中
    enablePopup: true,                   // 点击弹窗
    popupFields: ['name', 'value']       // 弹窗显示字段
  }],
  interactions: [{
    type: 'marker',
    longitude: 116.397,
    latitude: 39.909,
    content: '标记点',
    draggable: true
  }]
}
```

### 组件模式（编程式）

```tsx
import { Aimap, PointLayer, Marker } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <PointLayer
        source={data}
        sourceType="json"
        color="#1890ff"
        size={10}
        onClick={(e) => console.log('选中:', e.feature)}
        onMouseEnter={(e) => console.log('悬停:', e.feature)}
      />
      <Marker longitude={116.397} latitude={39.909} draggable>
        标记点
      </Marker>
    </Aimap>
  )
}
```
