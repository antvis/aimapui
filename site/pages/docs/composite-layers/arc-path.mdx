# 弧线流向 (ArcFlowLayer)

弧线流向图层是线图层的复合封装，内置弧线计算、动态粒子动画和优化渲染，适合 OD 流向可视化。

## Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', style: 'dark', center: [108.0, 34.0], zoom: 4 },
  layers: [{
    type: 'arcFlow',
    source: flowData,
    sourceType: 'json',
    sourceConfig: { x: 'fromLng', y: 'fromLat', x1: 'toLng', y1: 'toLat' },
    color: '#3B82F6',
    size: 2,
    animate: { enable: true, duration: 4, trailLength: 2 },
    style: { arcHeight: 0.5 }
  }]
}
```

## 组件用法

```tsx
import { Aimap, ArcFlowLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', style: 'dark', center: [108.0, 34.0], zoom: 4 }}>
      <ArcFlowLayer
        source={flowData}
        sourceType="json"
        sourceConfig={{ x: 'fromLng', y: 'fromLat', x1: 'toLng', y1: 'toLat' }}
        color="#3B82F6"
        size={2}
        animate={{ enable: true, duration: 4, trailLength: 2 }}
        style={{ arcHeight: 0.5 }}
      />
    </Aimap>
  )
}
```

## 弧线高度

`style.arcHeight` 控制弧线弯曲程度：

| arcHeight | 效果 |
|-----------|------|
| `0.1` | 近乎直线，轻微弧度 |
| `0.5` | 适中弧度（默认） |
| `1.0` | 大弧度，视觉冲击强 |

## 数据驱动流向

```tsx
{
  type: 'arcFlow',
  source: flowData,
  sourceType: 'json',
  sourceConfig: { x: 'fromLng', y: 'fromLat', x1: 'toLng', y1: 'toLat' },
  colorField: 'volume',
  colorValues: ['#93C5FD', '#3B82F6', '#1E3A8A'],
  sizeField: 'volume',
  sizeValues: [1, 4],
  animate: { enable: true, duration: 3, trailLength: 1 }
}
```
