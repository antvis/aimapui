# 六边形热力 (HexagonLayer)

六边形热力图层（蜂巢图）将点位数据聚合为规则六边形网格，相比经典热力更适合精确的统计分析。

## Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', style: 'dark', center: [116.397, 39.909], zoom: 10 },
  layers: [{
    type: 'hexagon',
    source: pointsData,
    sourceType: 'json',
    sizeField: 'count',
    colorField: 'count',
    colorValues: ['#0d1b3e', '#1b4f8a', '#3b82f6', '#fbbf24', '#ef4444'],
    style: { coverage: 0.9, opacity: 0.85 }
  }]
}
```

## 组件用法

```tsx
import { Aimap, HexagonLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', style: 'dark', center: [116.397, 39.909], zoom: 10 }}>
      <HexagonLayer
        source={pointsData}
        sourceType="json"
        sizeField="count"
        colorField="count"
        colorValues={['#0d1b3e', '#1b4f8a', '#3b82f6', '#fbbf24', '#ef4444']}
        style={{ coverage: 0.9, opacity: 0.85 }}
      />
    </Aimap>
  )
}
```

## 3D 六边形

```tsx
{
  type: 'hexagon',
  source: data,
  sourceType: 'json',
  sizeField: 'count',
  sizeValues: [0, 60],
  colorField: 'count',
  colorValues: ['#1E3A8A', '#3B82F6', '#FBBF24']
}
```

## 关键属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `size` / `sizeField` | `number` / `string` | 六边形高度（3D时） |
| `color` / `colorField` + `colorValues` | - | 填充颜色 |
| `style.coverage` | `number` | 六边形覆盖率 0~1，默认 1 |
| `style.opacity` | `number` | 透明度 0~1 |
