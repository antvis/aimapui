# 卫星图层 (SatelliteLayer)

卫星图层加载高德/天地图等卫星影像底图，叠加在地图上。

## Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 10 },
  layers: [
    { type: 'satellite' },
    {
      type: 'point',
      source: markers,
      sourceType: 'json',
      color: '#EF4444',
      size: 10
    }
  ]
}
```

## 组件用法

```tsx
import { Aimap, SatelliteLayer, PointLayer } from '@antv/aimapui'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <SatelliteLayer />
      <PointLayer source={markers} sourceType="json" color="#EF4444" size={10} />
    </Aimap>
  )
}
```

## 与区域填充组合

卫星底图 + 半透明行政区划：

```tsx
layers: [
  { type: 'satellite' },
  {
    type: 'polygon',
    source: regions,
    sourceType: 'geojson',
    color: 'rgba(59, 130, 246, 0.4)',
    style: { opacity: 0.5 }
  }
]
```
