# 图标图层 (IconFontLayer / IconImageLayer)

aimapkit 提供两种图标图层：`IconFontLayer` 使用 IconFont 字体图标，`IconImageLayer` 使用图片 URL。两者均基于 PointLayer 扩展，支持数据驱动的图标映射。

## IconFontLayer — 字体图标

### Schema 用法

```tsx
const schema = {
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 10 },
  layers: [{
    type: 'iconFont',
    source: [
      { lng: 116.397, lat: 39.909, name: '医院', type: 'hospital' },
      { lng: 121.473, lat: 31.230, name: '学校', type: 'school' }
    ],
    sourceType: 'json',
    iconField: 'type',
    iconValues: { hospital: '\ue601', school: '\ue602' },
    size: 20,
    color: '#3B82F6'
  }]
}
```

### 组件用法

```tsx
import { Aimap, IconFontLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <IconFontLayer
        source={data}
        sourceType="json"
        iconField="type"
        iconValues={{ hospital: '\ue601', school: '\ue602' }}
        size={20}
        color="#3B82F6"
      />
    </Aimap>
  )
}
```

## IconImageLayer — 图片图标

### Schema 用法

```tsx
{
  type: 'iconImage',
  source: data,
  sourceType: 'json',
  iconField: 'category',
  iconValues: {
    restaurant: 'https://cdn.example.com/restaurant.png',
    park: 'https://cdn.example.com/park.png'
  },
  size: 24
}
```

### 组件用法

```tsx
import { Aimap, IconImageLayer } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <IconImageLayer
        source={data}
        sourceType="json"
        iconField="category"
        iconValues={{
          restaurant: 'https://cdn.example.com/restaurant.png',
          park: 'https://cdn.example.com/park.png'
        }}
        size={24}
      />
    </Aimap>
  )
}
```

## 图标与标签组合

```tsx
layers: [
  { type: 'iconFont', source: pois, sourceType: 'json', iconField: 'type', iconValues: {...}, size: 20 },
  { type: 'point', source: pois, sourceType: 'json', shapeField: 'name', shapeValues: 'text', size: 11, color: '#0f172a', style: { textOffset: [0, 20] } }
]
```
