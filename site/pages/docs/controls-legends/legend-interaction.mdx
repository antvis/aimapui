# 图例交互

图例不仅展示颜色/大小的映射关系，还支持与地图联动交互，如筛选、高亮、缩放范围等。

## 图例与图层联动

```tsx
const schema = {
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 10 },
  layers: [{
    type: 'point',
    source: data,
    sourceType: 'json',
    colorField: 'category',
    colorValues: ['#3B82F6', '#10B981', '#F59E0B', '#EF4444']
  }],
  legends: [{
    type: 'categories',
    field: 'category',
    position: 'bottom-left',
    items: [
      { label: '商业', color: '#3B82F6', value: 'business' },
      { label: '住宅', color: '#10B981', value: 'residential' },
      { label: '工业', color: '#F59E0B', value: 'industrial' },
      { label: '公共', color: '#EF4444', value: 'public' }
    ],
    interactive: true  // 启用交互
  }]
}
```

## 图例交互行为

| 交互 | 说明 |
|------|------|
| 点击图例项 | 切换对应数据分类的显示/隐藏 |
| 悬停图例项 | 高亮对应分类的数据要素 |
| 拖拽图例 | 移动图例位置（需 `draggable: true`） |
| 点击连续图例范围 | 缩放地图到对应数据范围 |

## 分类图例交互

```tsx
import { Aimap, PointLayer, CategoriesLegend } from '@antv/aimapui'

function App() {
  const [visibleCategories, setVisibleCategories] = useState(new Set(['business', 'residential']))

  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <PointLayer
        source={filteredData}
        sourceType="json"
        colorField="category"
        colorValues={['#3B82F6', '#10B981', '#F59E0B', '#EF4444']}
      />
      <CategoriesLegend
        field="category"
        position="bottom-left"
        items={legendItems}
        onToggle={(value, active) => {
          const next = new Set(visibleCategories)
          active ? next.add(value) : next.delete(value)
          setVisibleCategories(next)
        }}
      />
    </Aimap>
  )
}
```

## 连续图例交互

```tsx
import { RampLegend } from '@antv/aimapui'

<RampLegend
  field="temperature"
  min={-10}
  max={40}
  colors={['#3B82F6', '#10B981', '#F59E0B', '#EF4444']}
  position="bottom-right"
  onRangeSelect={(min, max) => {
    // 过滤图层数据到选定范围
  }}
/>
```

## 可拖拽图例

```tsx
{
  type: 'categories',
  field: 'category',
  position: 'bottom-left',
  draggable: true,
  interactive: true
}
```
