# 性能优化

当地图数据量增大或需要在低端设备上运行时，以下优化策略可以显著提升渲染性能和交互流畅度。

## 数据优化

### 数据裁剪

只加载当前视口内的数据：

```tsx
// 组件模式：监听视口变化
<Aimap
  map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}
  onBoundsChange={(bounds) => {
    // 请求视口范围内的数据
    fetchData(bounds).then(setData)
  }}
/>
```

### 数据简化

对 GeoJSON 进行抽稀：

```tsx
// 减小数据精度
function simplifyCoordinates(coords: number[][], precision = 4) {
  return coords.map(([lng, lat]) => [
    Number(lng.toFixed(precision)),
    Number(lat.toFixed(precision))
  ])
}
```

## 渲染优化

### 减小绘制复杂度

```tsx
layers: [{
  type: 'point',
  source: bigData,
  sourceType: 'json',
  size: 6,                    // 小圆点比大圆点性能更好
  color: '#3B82F6',           // 固定颜色比字段映射快
  style: {
    opacity: 1,               // 不透明比半透明快
    strokeWidth: 0            // 关闭描边
  }
}]
```

### 关闭拾取

当不需要交互时关闭拾取：

```tsx
style: {
  enablePicking: false        // 大数据量关闭拾取
}
```

### 动画优化

```tsx
animate: {
  enable: true,
  duration: 4,
  trailLength: 1,
  // 性能优化
  interval: 0.5              // 降低帧率
}
```

## 图层优化

### 合理使用聚合

当点位超过 10000 个时推荐使用聚合：

```tsx
// 替代普通 PointLayer
{ type: 'markerCluster', source: bigData, sourceType: 'json', ... }
```

### 热力图替代大量点

```tsx
// 大量密集点用热力图代替
{ type: 'heatmap', source: bigData, sourceType: 'json', shape: 'heatmap', ... }
```

### 按缩放级别切换图层

```tsx
layers: [
  { type: 'heatmap', ..., minZoom: 3, maxZoom: 8 },   // 缩小用热力
  { type: 'point', ..., minZoom: 8, maxZoom: 18 }     // 放大用散点
]
```

## 内存优化

### 及时销毁

```tsx
import { useEffect } from 'react'

function MapComponent() {
  const mapRef = useRef(null)

  useEffect(() => {
    return () => {
      // 组件卸载时销毁地图实例
      mapRef.current?.destroy()
    }
  }, [])
}
```

### 虚拟化大数据

```tsx
// Schema 模式下使用 autoFit 控制初始视口
const schema = {
  map: { basemap: 'gaode', autoFit: true },
  layers: [{ type: 'point', source: data, sourceType: 'json', autoFit: true }]
}
```

## 性能清单

| 策略 | 场景 | 预期提升 |
|------|------|---------|
| 数据裁剪 | 大范围数据 | 50-90% |
| 关闭拾取 | 仅展示 | 30-50% |
| 聚合 | >1万点 | 显著 |
| 热力替代 | >5万点 | 显著 |
| 缩放分层 | 全量级 | 40-60% |
| 减小尺寸 | 通用 | 10-20% |
| 关闭动画 | 不需要 | 20-40% |
