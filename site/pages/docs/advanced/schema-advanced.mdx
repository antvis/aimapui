# Schema 进阶

当基础 Schema 用法无法满足需求时，可以使用高级特性：条件渲染、动态更新、响应式配置和 Schema 组合。

## 动态 Schema 更新

```tsx
import { Aimap } from '@antv/aimapkit'
import { useState, useEffect } from 'react'

function DynamicMap() {
  const [schema, setSchema] = useState(baseSchema)

  useEffect(() => {
    // 数据变化时更新 Schema
    fetch('/api/data').then(res => res.json()).then(data => {
      setSchema(prev => ({
        ...prev,
        layers: prev.layers.map(layer =>
          layer.type === 'point' ? { ...layer, source: data } : layer
        )
      }))
    })
  }, [])

  return <Aimap schema={schema} />
}
```

## 条件图层

```tsx
const schema = {
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 10 },
  layers: [
    {
      type: 'point',
      source: data,
      sourceType: 'json',
      color: '#3B82F6',
      size: 12,
      visible: true,         // 始终显示
      minZoom: 8,            // 仅在 zoom >= 8 时可见
      maxZoom: 16
    },
    {
      type: 'heatmap',
      source: data,
      sourceType: 'json',
      visible: true,
      minZoom: 3,            // 缩小时显示热力
      maxZoom: 8
    }
  ]
}
```

## Schema 组合

将多个 Schema 片段组合：

```tsx
function mergeSchemas(...schemas: Partial<AimapSchema>[]): AimapSchema {
  return schemas.reduce((acc, s) => ({
    map: { ...acc.map, ...s.map },
    layers: [...(acc.layers || []), ...(s.layers || [])],
    controls: [...(acc.controls || []), ...(s.controls || [])],
    legends: [...(acc.legends || []), ...(s.legends || [])]
  }), { map: {}, layers: [], controls: [], legends: [] })
}

// 使用
const finalSchema = mergeSchemas(
  baseMapSchema,
  trafficLayerSchema,
  legendSchema
)
```

## Schema 验证

```tsx
import { validateSchema } from '@antv/aimapkit'

const result = validateSchema(schema)
if (!result.valid) {
  console.error('Schema 验证失败:', result.errors)
}
```

## AI 友好

Schema 的 JSON 结构天然适合 AI 生成：

```json
{
  "map": { "basemap": "gaode", "center": [116.397, 39.909], "zoom": 10 },
  "layers": [
    { "type": "point", "source": "[DATA_URL]", "sourceType": "json", "color": "#3B82F6", "size": 12 }
  ]
}
```

AI 工具可以：
- 直接生成完整 Schema
- 根据自然语言描述修改 Schema
- 自动推断 `colorValues`、`sizeValues` 等映射参数
- 通过 `validateSchema()` 验证生成结果
