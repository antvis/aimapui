# 移动端适配

aimapui 针对移动端场景进行了深度优化，提供触摸手势、响应式布局和性能节流策略。

## 触摸手势

| 手势 | 行为 |
|------|------|
| 单指拖动 | 平移地图 |
| 双指捏合 | 缩放地图 |
| 双指旋转 | 旋转地图 |
| 双击 | 放大一级 |
| 长按 | 触发 contextmenu 事件 |

## 响应式地图容器

```tsx
import { Aimap } from '@antv/aimapui'

function App() {
  return (
    <div style={{ width: '100vw', height: '100vh' }}>
      <Aimap
        map={{
          basemap: 'gaode',
          center: [116.397, 39.909],
          zoom: 10,
          resizeEnable: true  // 自动跟随容器大小
        }}
      />
    </div>
  )
}
```

## 移动端优化配置

```tsx
const schema = {
  map: {
    basemap: 'gaode',
    center: [116.397, 39.909],
    zoom: 10,
    // 移动端优化
    rotateEnable: false,      // 禁用旋转（减少误触）
    pitchEnable: false,       // 禁用倾斜
    animateEnable: true,      // 启用动画
    jogEnable: false,         // 禁用慢速平移
    touchZoomCenter: 1        // 双指缩放中心
  }
}
```

## 移动端控件布局

移动端控件应精简且不遮挡地图：

```tsx
import { Aimap, PointLayer, ZoomControl, ScaleControl } from '@antv/aimapui'

function MobileMap() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <PointLayer source={data} sourceType="json" color="#3B82F6" size={12} />
      {/* 移动端只保留最必要的控件 */}
      <ZoomControl position="bottom-right" />
      <ScaleControl position="bottom-left" />
    </Aimap>
  )
}
```

## 性能节流

```tsx
// 大量数据时启用节流渲染
layers: [{
  type: 'point',
  source: bigData,
  sourceType: 'json',
  size: 6,
  color: '#3B82F6',
  style: {
    reduceBlur: true,       // 降低模糊效果
    enablePicking: false    // 移动端关闭拾取以提升性能
  }
}]
```

## 移动端适配 Hooks

```tsx
import { useMap, useMobileAdapt } from '@antv/aimapui'

function Map() {
  const { map } = useMap()
  const { isMobile, layout } = useMobileAdapt({
    breakpoint: 768,
    mobileZoom: 9,
    desktopZoom: 11
  })

  return (
    <Aimap map={{ basemap: 'gaode', zoom: isMobile ? 9 : 11 }}>
      {/* 移动端隐藏复杂图例 */}
      {!isMobile && <CategoriesLegend ... />}
    </Aimap>
  )
}
```
