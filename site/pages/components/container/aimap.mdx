# Aimap

Aimap 是 aimapkit 的根容器组件，负责初始化地图实例、管理底图引擎，并作为所有子图层和控件的 Provider。

## 导入

```tsx
import { Aimap } from '@antv/aimapkit'
```

## 用法

### 组件模式

```tsx
<Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
  <PointLayer source={data} sourceType="json" color="#3B82F6" size={12} />
</Aimap>
```

### Schema 模式

```tsx
<Aimap schema={{
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 10 },
  layers: [{ type: 'point', source: data, sourceType: 'json', color: '#3B82F6', size: 12 }]
}} />
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `map` | `MapConfig` | - | 地图配置（组件模式） |
| `schema` | `AimapSchema` | - | Schema 配置（Schema 模式） |
| `className` | `string` | - | 容器 className |
| `style` | `CSSProperties` | - | 容器样式 |
| `onReady` | `(scene) => void` | - | 地图就绪回调 |
| `onDestroy` | `() => void` | - | 地图销毁回调 |
| `onBoundsChange` | `(bounds) => void` | - | 视口变化回调 |
| `onZoomChange` | `(zoom) => void` | - | 缩放变化回调 |
| `onLayerClick` | `(e) => void` | - | 图层点击回调（Schema 模式） |

## MapConfig

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `basemap` | `'gaode' \| 'mapbox' \| 'maplibre' \| 'tianditu' \| 'tencent' \| 'baidu' \| 'l7'` | `'gaode'` | 底图引擎 |
| `style` | `string` | `'light'` | 地图样式 |
| `center` | `[number, number]` | `[116.397, 39.909]` | 中心点经纬度 |
| `zoom` | `number` | `10` | 缩放级别 |
| `pitch` | `number` | `0` | 倾斜角度 |
| `rotation` | `number` | `0` | 旋转角度 |
| `minZoom` | `number` | `0` | 最小缩放 |
| `maxZoom` | `number` | `18` | 最大缩放 |
| `token` | `string` | - | 地图服务 Token |
| `autoFit` | `boolean` | `false` | 自动适配数据范围 |
| `resizeEnable` | `boolean` | `true` | 跟随容器大小 |

## 事件

```tsx
<Aimap
  map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}
  onReady={(scene) => {
    console.log('地图就绪:', scene)
  }}
  onBoundsChange={(bounds) => {
    console.log('视口变化:', bounds)
  }}
>
  <PointLayer source={data} sourceType="json" />
</Aimap>
```
