# MapScene

MapScene 是 Aimap 的底层场景组件，提供对 @antv/l7 Scene 实例的直接访问，适合需要精细控制地图的场景。

## 导入

```tsx
import { MapScene } from '@antv/aimapui'
```

## 用法

```tsx
import { MapScene } from '@antv/aimapui'

function App() {
  return (
    <MapScene
      basemap="gaode"
      options={{ center: [116.397, 39.909], zoom: 10 }}
      onReady={(scene) => {
        // 直接使用 l7 Scene API
        scene.setCenter([121.473, 31.230])
      }}
    />
  )
}
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `basemap` | `string` | `'gaode'` | 底图引擎 |
| `options` | `MapOptions` | `{}` | 底图选项（原样传递给底层地图） |
| `onReady` | `(scene) => void` | - | 场景就绪回调 |
| `onDestroy` | `() => void` | - | 销毁回调 |
| `className` | `string` | - | 容器 className |
| `style` | `CSSProperties` | - | 容器样式 |

## 与 Aimap 的区别

| 特性 | Aimap | MapScene |
|------|-------|----------|
| Schema 模式 | 支持 | 不支持 |
| 组件子图层 | 支持 | 不支持 |
| Context Provider | 自动提供 | 不提供 |
| l7 Scene 直接访问 | 通过 `onReady` | 通过 `onReady` |
| 适用场景 | 通用开发 | 底层定制 |

## 何时使用 MapScene

- 需要直接操作 l7 Scene 实例
- 与已有 l7 项目集成
- 使用 Aimap 不支持的底层 API
