# RampLegend

渐变色带图例，适用于连续数值字段的颜色映射。

```tsx
import { RampLegend } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `field` | `string` | - | 关联字段名 |
| `position` | `string` | `'bottom-left'` | 图例位置 |
| `title` | `string` | - | 图例标题 |
| `className` | `string` | - | 自定义样式 |
| `min` | `number` | **必填** | 最小值 |
| `max` | `number` | **必填** | 最大值 |
| `colors` | `string[]` | **必填** | 色带颜色数组 |

## Schema 用法

```tsx
legends: [{
  type: 'ramp',
  field: 'category',
  position: 'bottom-left',
  // ... 类型特有属性
}]
```

## 示例

```tsx
<RampLegend field="value" position="bottom-left" title="图例" />
```
