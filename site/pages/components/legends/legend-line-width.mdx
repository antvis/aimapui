# LineWidthLegend

线宽图例，展示数值与线宽的对应关系。

```tsx
import { LineWidthLegend } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `field` | `string` | - | 关联字段名 |
| `position` | `string` | `'bottom-left'` | 图例位置 |
| `title` | `string` | - | 图例标题 |
| `className` | `string` | - | 自定义样式 |
| `min` | `number` | **必填** | 最小值 |
| `max` | `number` | **必填** | 最大值 |
| `color` | `string` | `'#3B82F6'` | 线颜色 |

## Schema 用法

```tsx
legends: [{
  type: 'line-width',
  field: 'category',
  position: 'bottom-left',
  // ... 类型特有属性
}]
```

## 示例

```tsx
<LineWidthLegend field="value" position="bottom-left" title="图例" />
```
