# SizeLegend

尺寸图例，展示数值与标记大小的对应关系。

```tsx
import { SizeLegend } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `field` | `string` | - | 关联字段名 |
| `position` | `string` | `'bottom-left'` | 图例位置 |
| `title` | `string` | - | 图例标题 |
| `className` | `string` | - | 自定义样式 |
| `min` | `number` | **必填** | 最小值 |
| `max` | `number` | **必填** | 最大值 |
| `minSize` | `number` | `4` | 最小标记尺寸 |
| `maxSize` | `number` | `40` | 最大标记尺寸 |

## Schema 用法

```tsx
legends: [{
  type: 'size',
  field: 'category',
  position: 'bottom-left',
  // ... 类型特有属性
}]
```

## 示例

```tsx
<SizeLegend field="value" position="bottom-left" title="图例" />
```
