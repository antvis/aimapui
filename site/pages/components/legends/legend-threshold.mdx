# ThresholdLegend

阈值图例，按断点划分区间，每个区间一种颜色。

```tsx
import { ThresholdLegend } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `field` | `string` | - | 关联字段名 |
| `position` | `string` | `'bottom-left'` | 图例位置 |
| `title` | `string` | - | 图例标题 |
| `className` | `string` | - | 自定义样式 |
| `thresholds` | `number[]` | **必填** | 阈值断点 |
| `colors` | `string[]` | **必填** | 区间颜色 |

## Schema 用法

```tsx
legends: [{
  type: 'threshold',
  field: 'category',
  position: 'bottom-left',
  // ... 类型特有属性
}]
```

## 示例

```tsx
<ThresholdLegend field="value" position="bottom-left" title="图例" />
```
