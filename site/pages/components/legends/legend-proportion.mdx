# ProportionLegend

比例图例，展示部分与整体的占比关系。

```tsx
import { ProportionLegend } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `field` | `string` | - | 关联字段名 |
| `position` | `string` | `'bottom-left'` | 图例位置 |
| `title` | `string` | - | 图例标题 |
| `className` | `string` | - | 自定义样式 |
| `total` | `number` | **必填** | 总量 |
| `items` | `ProportionItem[]` | **必填** | 分项列表 `{ label, value, color }` |

## Schema 用法

```tsx
legends: [{
  type: 'proportion',
  field: 'category',
  position: 'bottom-left',
  // ... 类型特有属性
}]
```

## 示例

```tsx
<ProportionLegend field="value" position="bottom-left" title="图例" />
```
