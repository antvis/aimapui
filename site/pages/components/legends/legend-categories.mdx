# CategoriesLegend

分类图例，展示离散类别与颜色的对应关系。

```tsx
import { CategoriesLegend } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `field` | `string` | - | 关联字段名 |
| `position` | `string` | `'bottom-left'` | 图例位置 |
| `title` | `string` | - | 图例标题 |
| `className` | `string` | - | 自定义样式 |
| `items` | `LegendItem[]` | **必填** | 图例项列表 `{ label, color, value }` |
| `interactive` | `boolean` | `false` | 是否启用交互（点击筛选） |
| `draggable` | `boolean` | `false` | 是否可拖拽 |

## Schema 用法

```tsx
legends: [{
  type: 'categories',
  field: 'category',
  position: 'bottom-left',
  // ... 类型特有属性
}]
```

## 示例

```tsx
<CategoriesLegend field="value" position="bottom-left" title="图例" />
```
