# DivergingLegend

发散图例，从负值经中点到正值的色带映射。

```tsx
import { DivergingLegend } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `field` | `string` | - | 关联字段名 |
| `position` | `string` | `'bottom-left'` | 图例位置 |
| `title` | `string` | - | 图例标题 |
| `className` | `string` | - | 自定义样式 |
| `min` | `number` | **必填** | 最小值（负） |
| `max` | `number` | **必填** | 最大值（正） |
| `colors` | `string[]` | **必填** | 色带数组 [负色, 中色, 正色] |

## Schema 用法

```tsx
legends: [{
  type: 'diverging',
  field: 'category',
  position: 'bottom-left',
  // ... 类型特有属性
}]
```

## 示例

```tsx
<DivergingLegend field="value" position="bottom-left" title="图例" />
```
