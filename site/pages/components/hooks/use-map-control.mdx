# useMapControl

地图控件 Hook，以编程方式控制图层显隐、尺寸适配等。

```tsx
import { useMapControl } from '@antv/aimapkit'
```

## 用法

```tsx
function LayerManager() {
  const { showLayer, hideLayer, fitBounds, resize } = useMapControl()

  return (
    <div>
      <button onClick={() => showLayer('heatmap')}>显示热力</button>
      <button onClick={() => hideLayer('heatmap')}>隐藏热力</button>
      <button onClick={() => fitBounds([[116.1, 39.6], [116.7, 40.2]])}>适配范围</button>
      <button onClick={resize}>重置大小</button>
    </div>
  )
}
```

## 返回值

| 属性 | 类型 | 说明 |
|------|------|------|
| `showLayer` | `(id: string) => void` | 显示图层 |
| `hideLayer` | `(id: string) => void` | 隐藏图层 |
| `fitBounds` | `(bounds: [[number,number],[number,number]]) => void` | 适配到范围 |
| `resize` | `() => void` | 触发地图重绘 |
