# SceneContext

场景上下文，提供对底层 Aimap/Scene 实例的访问。

```tsx
import { useScene } from '@antv/aimapui'
```

## 用法

```tsx
function MapInfo() {
  const { scene, map } = useScene()

  useEffect(() => {
    if (scene) {
      console.log('缩放级别:', scene.getZoom())
      console.log('中心点:', scene.getCenter())
    }
  }, [scene])

  return null
}
```

## 返回值

| 属性 | 类型 | 说明 |
|------|------|------|
| `scene` | `Scene \| null` | l7 Scene 实例 |
| `map` | `MapInstance \| null` | 底层地图实例 |
