# ThemeContext

主题上下文，提供当前主题和切换主题的能力。

```tsx
import { useTheme } from '@antv/aimapkit'
```

## 用法

```tsx
function ThemeToggle() {
  const { theme, setTheme, tokens } = useTheme()

  return (
    <button onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}>
      当前: {theme}, 主色: {tokens.primary}
    </button>
  )
}
```

## 返回值

| 属性 | 类型 | 说明 |
|------|------|------|
| `theme` | `'light' \| 'dark'` | 当前主题 |
| `setTheme` | `(theme) => void` | 切换主题 |
| `tokens` | `DesignTokens` | 设计 Token |
