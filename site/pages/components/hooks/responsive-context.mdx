# ResponsiveContext

响应式上下文，提供视口和设备信息，用于自适应布局。

```tsx
import { useResponsive } from '@antv/aimapkit'
```

## 用法

```tsx
function AdaptiveUI() {
  const { isMobile, isTablet, isDesktop, width, height, breakpoint } = useResponsive()

  return (
    <div>
      {isMobile && <MobileToolbar />}
      {isDesktop && <SidePanel />}
      <p>视口: {width}x{height}, 断点: {breakpoint}</p>
    </div>
  )
}
```

## 返回值

| 属性 | 类型 | 说明 |
|------|------|------|
| `isMobile` | `boolean` | 是否移动端 (&lt;768px) |
| `isTablet` | `boolean` | 是否平板 (768-1024px) |
| `isDesktop` | `boolean` | 是否桌面 (>1024px) |
| `width` | `number` | 视口宽度 |
| `height` | `number` | 视口高度 |
| `breakpoint` | `string` | 当前断点名 |
