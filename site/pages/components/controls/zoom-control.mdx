# ZoomControl

地图缩放控件，提供放大/缩小按钮。

```tsx
import { ZoomControl } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `position` | `'top-left' \| 'top-right' \| 'bottom-left' \| 'bottom-right'` | `'top-right'` | 控件位置 |
| `showZoom` | `boolean` | `true` | 显示当前缩放级别 |
| `className` | `string` | - | 自定义样式类名 |

## 示例

```tsx
<ZoomControl position="bottom-right" showZoom />
```
