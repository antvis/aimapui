# FullscreenControl

全屏控件，点击切换全屏模式。

```tsx
import { FullscreenControl } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `position` | `string` | `'top-right'` | 控件位置 |
| `className` | `string` | - | 自定义样式类名 |

## 示例

```tsx
<FullscreenControl position="top-right" />
```
