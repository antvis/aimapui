# ScaleControl

地图比例尺控件。

```tsx
import { ScaleControl } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `position` | `string` | `'bottom-left'` | 控件位置 |
| `unit` | `'metric' \| 'imperial'` | `'metric'` | 单位制 |
| `className` | `string` | - | 自定义样式类名 |

## 示例

```tsx
<ScaleControl position="bottom-left" unit="metric" />
```
