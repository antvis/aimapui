# LayerSwitchControl

图层显隐切换控件，带复选框的图层列表面板。

```tsx
import { LayerSwitchControl } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `position` | `string` | `'top-right'` | 控件位置 |
| `layers` | `LayerConfig[]` | - | 图层列表配置 |
| `className` | `string` | - | 自定义样式类名 |

### LayerConfig

| 属性 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 图层 ID |
| `name` | `string` | 显示名称 |
| `visible` | `boolean` | 初始是否可见 |

## 示例

```tsx
<LayerSwitchControl layers={[
  { id: 'points', name: '点位', visible: true },
  { id: 'heatmap', name: '热力', visible: false },
  { id: 'flow', name: '流向', visible: true }
]} />
```
