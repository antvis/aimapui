# ExportImageControl

地图导出控件，将当前地图导出为图片。

```tsx
import { ExportImageControl } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `position` | `string` | `'top-right'` | 控件位置 |
| `format` | `'png' \| 'jpeg'` | `'png'` | 导出格式 |
| `quality` | `number` | `1` | JPEG 质量 (0-1) |
| `onExport` | `(blob) => void` | - | 导出回调 |
| `className` | `string` | - | 自定义样式类名 |

## 示例

```tsx
<ExportImageControl format="png" onExport={(blob) => { const url = URL.createObjectURL(blob); /* download */ }} />
```
