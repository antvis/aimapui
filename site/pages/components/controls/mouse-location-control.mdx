# MouseLocationControl

鼠标位置控件，实时显示鼠标经纬度。

```tsx
import { MouseLocationControl } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `position` | `string` | `'bottom-right'` | 控件位置 |
| `format` | `(lng, lat) => string` | - | 自定义格式化函数 |
| `className` | `string` | - | 自定义样式类名 |

## 示例

```tsx
<MouseLocationControl position="bottom-right" format={(lng, lat) => `${lng.toFixed(4)}, ${lat.toFixed(4)}`} />
```
