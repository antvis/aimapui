# HexagonLayer

六边形蜂窝热力图层，将点聚合为规则六边形网格。

```tsx
import { HexagonLayer } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | **必填** | 数据源 |
| `sourceType` | `string` | `'json'` | 数据源类型 |
| `sizeField` | `string` | - | 高度映射字段 |
| `sizeValues` | `[number, number]` | - | 高度范围 |
| `colorField` | `string` | - | 颜色映射字段 |
| `colorValues` | `string[]` | - | 颜色值域 |
| `style` | `object` | - | `{ coverage, opacity }` |
| `visible` | `boolean` | `true` | 可见性 |

## 示例

```tsx
<HexagonLayer source={data} sourceType="json" sizeField="count" colorField="count" colorValues={['#0d1b3e', '#3B82F6', '#FBBF24']} style={{ coverage: 0.9, opacity: 0.85 }} />
```
