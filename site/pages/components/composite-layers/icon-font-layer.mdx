# IconFontLayer

IconFont 字体图标图层，适用于 POI 标注。

```tsx
import { IconFontLayer } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | **必填** | 数据源 |
| `sourceType` | `string` | `'json'` | 数据源类型 |
| `iconField` | `string` | **必填** | 图标字段名 |
| `iconValues` | `Record<string, string>` | **必填** | 字段值到图标 unicode 映射 |
| `size` | `number` | `20` | 图标大小 |
| `color` | `string` | `'#3B82F6'` | 图标颜色 |
| `style` | `object` | - | `{ opacity }` |
| `visible` | `boolean` | `true` | 可见性 |

## 示例

```tsx
<IconFontLayer source={pois} sourceType="json" iconField="type" iconValues={{ hospital: '\ue601', school: '\ue602', park: '\ue603' }} size={20} color="#3B82F6" />
```
