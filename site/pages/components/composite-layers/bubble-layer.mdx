# BubbleLayer

气泡图层，使用圆的大小编码数值，适用于分级统计地图。

```tsx
import { BubbleLayer } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | **必填** | 数据源（GeoJSON） |
| `sourceType` | `string` | `'geojson'` | 数据源类型 |
| `colorField` | `string` | - | 颜色映射字段 |
| `colorValues` | `string[]` | - | 颜色映射值域 |
| `sizeField` | `string` | - | 气泡大小映射字段 |
| `sizeValues` | `[number, number]` | `[8, 40]` | 气泡大小范围 |
| `style` | `object` | - | `{ opacity, stroke, strokeWidth }` |
| `active` | `object` | - | 悬停高亮 |
| `visible` | `boolean` | `true` | 可见性 |

## 示例

```tsx
<BubbleLayer source={provinces} sourceType="geojson" sizeField="population" sizeValues={[8, 50]} colorField="gdp" colorValues={['#DBEAFE', '#3B82F6', '#1E3A8A']} style={{ opacity: 0.8 }} />
```
