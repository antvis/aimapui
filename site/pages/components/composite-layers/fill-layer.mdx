# FillLayer

分级填充图层，ChinaDistrictLayer 的基础版本，不绑定行政区划数据。

```tsx
import { FillLayer } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | **必填** | GeoJSON 数据源 |
| `sourceType` | `string` | `'geojson'` | 数据源类型 |
| `colorField` | `string` | - | 颜色映射字段 |
| `colorValues` | `string[]` | - | 颜色值域 |
| `style` | `object` | - | `{ opacity, stroke, strokeWidth }` |
| `active` | `object` | - | 悬停高亮 |
| `select` | `object` | - | 点击选中 |
| `visible` | `boolean` | `true` | 可见性 |

## 示例

```tsx
<FillLayer source={customRegions} sourceType="geojson" colorField="density" colorValues={['#FEF3C7', '#F59E0B', '#B45309']} style={{ opacity: 0.75 }} active={{ color: '#FBBF24' }} />
```
