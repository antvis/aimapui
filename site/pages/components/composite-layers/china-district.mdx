# ChinaDistrictLayer

中国行政区划图层，内置省市区数据和下钻交互。

```tsx
import { ChinaDistrictLayer } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | - | 绑定的数据源 |
| `sourceType` | `string` | `'json'` | 数据源类型 |
| `adCode` | `string` | `'100000'` | 行政区划代码 |
| `depth` | `0 \| 1 \| 2` | `1` | 展示深度 |
| `colorField` | `string` | - | 颜色映射字段 |
| `colorValues` | `string[]` | - | 颜色映射值域 |
| `style` | `object` | - | `{ opacity, stroke, strokeWidth }` |
| `active` | `object` | - | 悬停高亮 |
| `onClick` | `(e) => void` | - | 点击事件，可获取 adcode |

## 示例

```tsx
const [adCode, setAdCode] = useState('100000')
<ChinaDistrictLayer source={data} adCode={adCode} depth={1} colorField="value" colorValues={['#DBEAFE', '#1E3A8A']} onClick={(e) => setAdCode(e.feature.properties.adcode)} />
```
