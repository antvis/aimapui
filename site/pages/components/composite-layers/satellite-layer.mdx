# SatelliteLayer

卫星影像底图图层。

```tsx
import { SatelliteLayer } from '@antv/aimapkit'
```

## Props

无额外 Props，直接使用即可叠加卫星影像。

## 示例

```tsx
<Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
  <SatelliteLayer />
  <PointLayer source={markers} sourceType="json" color="#EF4444" size={10} />
</Aimap>
```
