# Tooltip

工具提示组件，鼠标悬停时显示轻量信息。

```tsx
import { Tooltip } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `lngLat` | `[number, number]` | **必填** | 经纬度 |
| `title` | `string` | - | 标题 |
| `items` | `TooltipItem[]` | - | 键值对列表 |
| `variant` | `'light' \| 'dark'` | `'dark'` | 风格变体 |
| `direction` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` | 弹出方向 |
| `trigger` | `'hover' \| 'click'` | `'hover'` | 触发方式 |
| `className` | `string` | - | 自定义样式 |

### TooltipItem

| 属性 | 类型 | 说明 |
|------|------|------|
| `label` | `string` | 字段名 |
| `value` | `string \| number` | 字段值 |
| `color` | `string` | 标记颜色 |

## 示例

```tsx
<Tooltip
  lngLat={[116.397, 39.909]}
  title="北京"
  items={[
    { label: 'GDP', value: '4.3万亿', color: '#3B82F6' },
    { label: '人口', value: '2189万', color: '#10B981' }
  ]}
  variant="dark"
/>
```
