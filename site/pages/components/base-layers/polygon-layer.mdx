# PolygonLayer

在地图上渲染区域填充，支持3D挤出效果。

```tsx
import { PolygonLayer } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | **必填** | 数据源 |
| `sourceType` | `string` | `'geojson'` | 数据源类型 |
| `color` | `string` | `'#3B82F6'` | 填充色 |
| `colorField` | `string` | - | 颜色映射字段 |
| `colorValues` | `string[]` | - | 颜色映射值域 |
| `size` | `number` | `0` | 3D挤出高度 |
| `sizeField` | `string` | - | 高度映射字段 |
| `sizeValues` | `[number, number]` | - | 高度映射值域 |
| `style` | `object` | - | `{ opacity, stroke, strokeWidth }` |
| `active` | `object` | - | 悬停高亮 |
| `select` | `object` | - | 点击选中 |
| `visible` | `boolean` | `true` | 可见性 |
| `zIndex` | `number` | `0` | 层级 |

## 示例

### 分级填充

```tsx
<PolygonLayer source={regions} sourceType="geojson" colorField="gdp" colorValues={['#DBEAFE', '#3B82F6', '#1E3A8A']} style={{ opacity: 0.8 }} active={{ color: '#F59E0B' }} />
```

### 3D 建筑

```tsx
<PolygonLayer source={buildings} sourceType="geojson" sizeField="height" sizeValues={[0, 500]} color="#60A5FA" style={{ opacity: 0.85 }} />
```
