# ImageLayer

在地图上叠加单张图片。

```tsx
import { ImageLayer } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `object` | **必填** | `{ x, y, x1, y1, image }` |
| `sourceType` | `'image'` | `'image'` | 固定为 image |
| `style` | `object` | - | `{ opacity }` |
| `visible` | `boolean` | `true` | 可见性 |

## 示例

```tsx
<ImageLayer source={{ x: 116.2, y: 39.7, x1: 116.6, y1: 40.1, image: '/overlay.png' }} sourceType="image" style={{ opacity: 0.7 }} />
```
