# PointLayer

在地图上渲染离散点位，支持散点、3D柱体和文本标注。

```tsx
import { PointLayer } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | **必填** | 数据源 |
| `sourceType` | `'json' \| 'geojson' \| 'csv'` | `'json'` | 数据源类型 |
| `sourceConfig` | `object` | - | 数据解析配置 `{ x, y, x1, y1 }` |
| `color` | `string` | `'#3B82F6'` | 固定颜色 |
| `colorField` | `string` | - | 颜色映射字段 |
| `colorValues` | `string[]` | - | 颜色映射值域 |
| `size` | `number` | `12` | 固定大小（px） |
| `sizeField` | `string` | - | 大小映射字段 |
| `sizeValues` | `[number, number]` | - | 大小映射值域 |
| `shape` | `string` | `'circle'` | 形状：`circle` `square` `triangle` `diamond` `cylinder` `text` |
| `shapeField` | `string` | - | 形状映射字段 |
| `style` | `object` | - | 样式：`opacity` `strokeWidth` `stroke` `textAllowOverlap` |
| `animate` | `object` | - | 动画配置 |
| `active` | `object` | - | 悬停高亮 `{ color }` |
| `select` | `object` | - | 点击选中 `{ color }` |
| `visible` | `boolean` | `true` | 是否可见 |
| `zIndex` | `number` | `0` | 层级 |
| `minZoom` | `number` | - | 最小可见缩放 |
| `maxZoom` | `number` | - | 最大可见缩放 |
| `autoFit` | `boolean` | `false` | 自动适配数据范围 |

## 事件

| 事件 | 类型 | 说明 |
|------|------|------|
| `onClick` | `(e: LayerEvent) => void` | 点击 |
| `onMouseEnter` | `(e: LayerEvent) => void` | 鼠标进入 |
| `onMouseLeave` | `(e: LayerEvent) => void` | 鼠标离开 |
| `onDoubleClick` | `(e: LayerEvent) => void` | 双击 |
| `onRightClick` | `(e: LayerEvent) => void` | 右键 |

## 示例

### 散点图

```tsx
<PointLayer source={cities} sourceType="json" colorField="category" colorValues={['#3B82F6', '#10B981', '#F59E0B']} size={10} />
```

### 3D 柱体

```tsx
<PointLayer source={data} sourceType="json" shape="cylinder" sizeField="value" sizeValues={[5, 30]} colorField="value" colorValues={['#93C5FD', '#1D4ED8']} />
```

### 文本标注

```tsx
<PointLayer source={labels} sourceType="json" shapeField="name" shapeValues="text" size={12} color="#0f172a" style={{ stroke: '#fff', strokeWidth: 2 }} />
```
