# LineLayer

在地图上渲染线段、弧线和路径，支持飞线动画。

```tsx
import { LineLayer } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | **必填** | 数据源 |
| `sourceType` | `string` | `'json'` | 数据源类型 |
| `sourceConfig` | `object` | - | 解析配置 `{ x, y, x1, y1 }` |
| `color` | `string` | `'#3B82F6'` | 线颜色 |
| `colorField` | `string` | - | 颜色映射字段 |
| `colorValues` | `string[]` | - | 颜色映射值域 |
| `size` | `number` | `2` | 线宽（px） |
| `sizeField` | `string` | - | 线宽映射字段 |
| `sizeValues` | `[number, number]` | - | 线宽映射值域 |
| `shape` | `string` | `'line'` | 形状：`line` `arc` `greatcircle` `flowline` `path` `isoline` |
| `animate` | `object` | - | `{ enable, duration, trailLength }` |
| `style` | `object` | - | `{ opacity, lineType }` |
| `active` | `object` | - | 悬停高亮 |
| `visible` | `boolean` | `true` | 可见性 |
| `zIndex` | `number` | `0` | 层级 |

## 事件

| 事件 | 类型 | 说明 |
|------|------|------|
| `onClick` | `(e: LayerEvent) => void` | 点击 |
| `onMouseEnter` | `(e: LayerEvent) => void` | 鼠标进入 |
| `onMouseLeave` | `(e: LayerEvent) => void` | 鼠标离开 |

## 示例

### 飞线

```tsx
<LineLayer source={flows} sourceType="json" sourceConfig={{ x: 'fromLng', y: 'fromLat', x1: 'toLng', y1: 'toLat' }} shape="greatcircle" color="#F59E0B" size={2} animate={{ enable: true, duration: 4, trailLength: 2 }} />
```
