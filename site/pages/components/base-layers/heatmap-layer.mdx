# HeatmapLayer

渲染数据密度分布，支持经典热力和蜂窝热力。

```tsx
import { HeatmapLayer } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `source` | `any` | **必填** | 数据源 |
| `sourceType` | `string` | `'json'` | 数据源类型 |
| `shape` | `'heatmap' \| 'hexagon'` | `'heatmap'` | 热力形态 |
| `color` | `string[]` | 默认热力色 | 色带 |
| `colorField` | `string` | - | 颜色映射字段 |
| `sizeField` | `string` | - | 权重字段 |
| `sizeValues` | `[number, number]` | - | 3D六边形高度范围 |
| `style` | `object` | - | `{ coverage, opacity, intensity, radius }` |
| `visible` | `boolean` | `true` | 可见性 |

## 示例

```tsx
<HeatmapLayer source={pois} sourceType="json" shape="heatmap" sizeField="weight" color={['#0d0366', '#3e0f8f', '#b93289', '#f58c6c', '#fbdd7e']} />
```
