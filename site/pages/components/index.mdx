| [Schema 类型](/components/schema-types) | 类型定义与工具函数 | 3 |

## 两种使用方式

### Schema 模式

```jsx
const schema = {
  map: { basemap: 'gaode', zoom: 10 },
  layers: [{ type: 'point', source: data, colorField: 'category' }]
}
<Aimap schema={schema} />
```

### 组件模式

```jsx
<Aimap map={{ basemap: 'gaode', zoom: 10 }}>
  <PointLayer source={data} colorField="category" />
</Aimap>
```
