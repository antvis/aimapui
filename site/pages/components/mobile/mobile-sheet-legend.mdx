# MobileSheetLegend

移动端底部抽屉式图例，在小屏幕上以 sheet 形式展示图例。

```tsx
import { MobileSheetLegend } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `visible` | `boolean` | `false` | 是否可见 |
| `onClose` | `() => void` | - | 关闭回调 |
| `type` | `'categories' \| 'ramp' \| 'size'` | `'categories'` | 图例类型 |
| `items` | `any[]` | - | 图例数据 |
| `field` | `string` | - | 关联字段 |

## 示例

```tsx
<MobileSheetLegend visible={showLegend} onClose={() => setShowLegend(false)} type="ramp" field="temperature" items={[...]} />
```
