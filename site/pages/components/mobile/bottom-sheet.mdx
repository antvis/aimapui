# BottomSheet

移动端底部抽屉组件，用于展示详情面板、筛选器等。

```tsx
import { BottomSheet } from '@antv/aimapkit'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `visible` | `boolean` | `false` | 是否可见 |
| `height` | `number \| string` | `'50%'` | 抽屉高度 |
| `onClose` | `() => void` | - | 关闭回调 |
| `children` | `ReactNode` | - | 内容 |
| `draggable` | `boolean` | `true` | 可拖拽调整高度 |
| `className` | `string` | - | 自定义样式 |

## 示例

```tsx
<BottomSheet visible={showDetail} onClose={() => setShowDetail(false)} height="40%">
  <h3>POI 详情</h3>
  <p>{selectedPoi.name}</p>
</BottomSheet>
```
