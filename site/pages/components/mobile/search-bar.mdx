# SearchBar

移动端/桌面端搜索栏，支持地点搜索和自动补全。

```tsx
import { SearchBar } from '@antv/aimapui'
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| `placeholder` | `string` | `'搜索地点...'` | 占位文字 |
| `onSearch` | `(value: string) => void` | - | 搜索回调 |
| `onSelect` | `(result: SearchResult) => void` | - | 选择结果回调 |
| `position` | `string` | `'top-center'` | 位置 |
| `className` | `string` | - | 自定义样式 |

## 示例

```tsx
<SearchBar placeholder="搜索地点" onSearch={(v) => handleSearch(v)} onSelect={(r) => flyTo(r.lngLat)} />
```
