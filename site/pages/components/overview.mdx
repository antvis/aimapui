# 组件总览

aimapkit 提供两种使用模式：**Schema 模式**（声明式 JSON 配置）和**组件模式**（React JSX 组合），涵盖 50+ 组件，满足从简单标注到复杂应用的全部需求。

## 组件分类

### 容器

| 组件 | 说明 |
|------|------|
| `Aimap` | 主入口组件，支持 Schema 和组件两种模式 |
| `MapSceneRenderer` | 底图渲染器，管理 L7 Scene 生命周期 |

### 基础图层 (6)

| 组件 | 说明 | 图层类型 |
|------|------|---------|
| `PointLayer` | 点图层 | 散点、柱状、文本标注 |
| `LineLayer` | 线图层 | 路径、弧线、流向动画 |
| `PolygonLayer` | 面图层 | 区域填充、3D 建筑 |
| `HeatmapLayer` | 热力图层 | 经典热力、蜂窝热力 |
| `RasterLayer` | 栅格图层 | 栅格瓦片、影像数据 |
| `ImageLayer` | 图片图层 | 图片叠加 |

| 组件 | 说明 |
|------|------|

| `HexagonLayer` | 蜂窝热力图（六边形聚合） |
| `IconFontLayer` | 字体图标标注（Material Symbols） |
| `IconImageLayer` | 图片图标标注（缩放自适应） |

| `MarkerClusterLayer` | 大规模标注聚合（蜘蛛布局） |
| `SatelliteLayer` | 卫星影像图层（高德/谷歌/天地图） |

## 双模式 API

### Schema 模式

```tsx
import { Aimap } from '@antv/aimapkit'

const schema = {
  map: { basemap: 'gaode', center: [116.397, 39.909], zoom: 10 },
  layers: [{
    type: 'point',
    source: data,
    sourceType: 'json',
    color: '#3B82F6',
    size: 10
  }],
  controls: [{ type: 'zoom', position: 'topright' }]
}

function App() {
  return <Aimap schema={schema} />
}
```

### 组件模式

```tsx
import { Aimap, PointLayer, ZoomControl } from '@antv/aimapkit'

function App() {
  return (
    <Aimap map={{ basemap: 'gaode', center: [116.397, 39.909], zoom: 10 }}>
      <PointLayer
        source={data}
        sourceType="json"
        color="#3B82F6"
        size={10}
        onClick={(e) => console.log('clicked:', e.feature)}
      />
      <ZoomControl position="topright" />
    </Aimap>
  )
}
```

选择指南请参阅 [Schema 模式 vs 组件模式](/docs/getting-started/schema-vs-component)。
