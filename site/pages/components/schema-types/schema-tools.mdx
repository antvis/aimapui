# Schema 工具函数

aimapkit 提供的 Schema 相关工具函数。

## validateSchema

验证 Schema 结构的正确性。

```tsx
import { validateSchema } from '@antv/aimapkit'

const result = validateSchema(schema)
if (!result.valid) {
  console.error('验证失败:', result.errors)
  // [{ path: 'layers[0].type', message: '未知的图层类型: foo' }]
}
```

## mergeSchemas

合并多个 Schema 片段。

```tsx
import { mergeSchemas } from '@antv/aimapkit'

const full = mergeSchemas(baseSchema, dataSchema, legendSchema)
```

## createDefaultSchema

创建一个带默认值的 Schema。

```tsx
import { createDefaultSchema } from '@antv/aimapkit'

const schema = createDefaultSchema({
  basemap: 'gaode',
  center: [116.397, 39.909],
  zoom: 10
})
// { map: { basemap: 'gaode', center: [...], zoom: 10, style: 'light', ... }, layers: [], controls: [], legends: [] }
```

## cloneSchema

深拷贝 Schema（避免引用问题）。

```tsx
import { cloneSchema } from '@antv/aimapkit'

const copy = cloneSchema(originalSchema)
```

## diffSchemas

比较两个 Schema 的差异。

```tsx
import { diffSchemas } from '@antv/aimapkit'

const changes = diffSchemas(oldSchema, newSchema)
// [{ path: 'layers[0].color', oldValue: '#3B82F6', newValue: '#EF4444' }]
```
