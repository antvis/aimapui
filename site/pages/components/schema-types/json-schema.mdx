# JSON Schema

aimapkit Schema 的 JSON Schema 定义，可用于 IDE 自动补全和 AI 工具验证。

## 用途

- **IDE 自动补全**：在 VS Code 中配置 `$schema` 获得智能提示
- **AI 生成验证**：AI 工具生成 Schema 后自动验证
- **运行时校验**：`validateSchema()` 底层使用此定义

## 在 VS Code 中使用

在 JSON 文件顶部添加：

```json
{
  "$schema": "https://aimapkit.antv.antgroup.com/schema/aimap-schema.json",
  "map": { ... },
  "layers": [ ... ]
}
```

## 获取 JSON Schema

```tsx
import { aimapJsonSchema } from '@antv/aimapkit'

// 获取完整 JSON Schema 对象
console.log(JSON.stringify(aimapJsonSchema, null, 2))
```

## 类型生成

```bash
# 从 JSON Schema 生成 TypeScript 类型
npx json2ts https://aimapkit.antv.antgroup.com/schema/aimap-schema.json -o src/types/aimap.ts
```
