# @antv/aimapkit

Schema 驱动的 React 地图可视化组件库,基于 L7 构建。

## 快速开始

```bash
npm install @antv/aimapkit
```

## 核心特性

- 🎯 **Schema 驱动** - 只需 JSON 配置即可渲染地图
- 🎨 **现代化设计** - 蓝色主题,毛玻璃效果,微交互动效
- 📱 **响应式** - 自适应移动端和 PC 端
- 🔧 **丰富的组件** - 6 种图层、8 种控件、4 种图例
