# Tooltip 工具提示规范

Tooltip 是鼠标悬停时显示的轻量信息卡片，展示要素的关键数据。

## 变体

| 变体 | 背景 | 文字 | 适用场景 |
|------|------|------|---------|
| `dark` | `rgba(0,0,0,0.85)` | `#F8FAFC` | 亮色底图 |
| `light` | `rgba(255,255,255,0.95)` | `#0F172A` | 暗色底图 |

## 结构

### 基础 Tooltip
```
┌──────────────┐
│ 标题         │
├──────────────┤
│ ● 指标1  值1 │
│ ● 指标2  值2 │
└──────────────┘
```

### 结构化 Tooltip
```
┌─────────────────┐
│ 标题             │
├─────────────────┤
│ 🟢 指标1    值1  │
│ 🔵 指标2    值2  │
│ 🟡 指标3    值3  │
└─────────────────┘
```

## 样式

| 元素 | 值 |
|------|-----|
| 圆角 | `6px` |
| 内边距 | `8px 12px` |
| 标题字号 | `13px/600` |
| 正文字号 | `12px/400` |
| 色标 | `8px` 圆形 |
| 最大宽度 | `200px` |
| 延迟显示 | `100ms` |
| 延迟隐藏 | `50ms` |

## 方向

| 方向 | 说明 |
|------|------|
| `top` | 默认 |
| `bottom` | 上方空间不足时 |
| `left` / `right` | 特殊布局 |

## 触发方式

| 方式 | 说明 |
|------|------|
| `hover` | 默认，鼠标悬停 |
| `click` | 点击触发（移动端） |

## Schema 示例

```tsx
interactions: [{
  type: 'tooltip',
  trigger: 'hover',
  variant: 'dark',
  direction: 'top',
  title: { field: 'name' },
  items: [
    { label: 'GDP', field: 'gdp', color: '#3B82F6' },
    { label: '人口', field: 'population', color: '#10B981' }
  ]
}]
```

## 组件示例

```tsx
<Tooltip
  lngLat={[116.397, 39.909]}
  title="北京"
  items={[
    { label: 'GDP', value: '4.3万亿', color: '#3B82F6' },
    { label: '人口', value: '2189万', color: '#10B981' }
  ]}
  variant="dark"
/>
```
