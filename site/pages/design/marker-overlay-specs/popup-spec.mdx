# Popup 弹窗规范

Popup 是在地图点位上方弹出的信息卡片，展示结构化的详情数据。

## 尺寸

| 尺寸 | 宽度 | 最大高度 | 适用场景 |
|------|------|---------|---------|
| `sm` | 200px | 120px | 简要信息 |
| `md` | 280px | 200px | 标准信息 |
| `lg` | 360px | 320px | 丰富详情 |

## 结构

```
┌────────────────────────┐
│ 标题            [关闭]  │
├────────────────────────┤
│ 键值对1    值1         │
│ 键值对2    值2         │
│ 键值对3    值3         │
├────────────────────────┤
│ [操作按钮1] [操作按钮2]  │
└────────────────────────┘
```

## 样式

| 元素 | Light | Dark |
|------|-------|------|
| 背景 | `#FFFFFF` | `#1E293B` |
| 圆角 | `8px` | `8px` |
| 阴影 | `0 4px 12px rgba(0,0,0,0.15)` | `0 4px 12px rgba(0,0,0,0.4)` |
| 标题字号 | `14px/600` | `14px/600` |
| 正文字号 | `12px/400` | `12px/400` |
| 箭头 | 8px 三角 | 8px 三角 |

## 放置

| 位置 | 说明 |
|------|------|
| `top` | 默认，向上弹出 |
| `bottom` | 向下弹出 |
| `left` | 向左弹出 |
| `right` | 向右弹出 |

## 单例模式

开启 `singleton` 后，同一时刻只显示一个 Popup，新 Popup 弹出时自动关闭旧的。

## Schema 示例

```tsx
interactions: [{
  type: 'popup',
  trigger: 'click',
  size: 'md',
  placement: 'top',
  singleton: true,
  content: [
    { key: '名称', field: 'name' },
    { key: '人口', field: 'population' },
    { key: 'GDP', field: 'gdp' }
  ]
}]
```
