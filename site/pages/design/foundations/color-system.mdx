# 颜色系统

aimapui 颜色系统包含 UI 颜色和地图可视化色板两部分，确保控件与地图视觉协调统一。

## 地图底图色板

### 亮色底图

| 用途 | 色值 | 预览 |
|------|------|------|
| 水域 | `#C8DAE9` | 浅蓝 |
| 绿地 | `#C8E6B5` | 浅绿 |
| 道路 | `#FFFFFF` | 白色 |
| 建筑 | `#E8E0D8` | 米色 |
| 文字 | `#5A5A5A` | 深灰 |
| 边界 | `#B8B8B8` | 中灰 |

### 暗色底图

| 用途 | 色值 | 预览 |
|------|------|------|
| 水域 | `#0D2137` | 深蓝 |
| 绿地 | `#0E2A1C` | 深绿 |
| 道路 | `#1A1A2E` | 暗紫 |
| 建筑 | `#1C1E2A` | 暗灰 |
| 文字 | `#8E9AAF` | 浅灰蓝 |
| 边界 | `#2A2A3E` | 灰紫 |

## 数据可视化色板

### 顺序色板 (Sequential)

| 名称 | 色带 | 适用场景 |
|------|------|---------|
| Blue | `#DBEAFE → #1E3A8A` | 通用数值 |
| Green | `#D1FAE5 → #064E3B` | 正向指标 |
| Red | `#FEE2E2 → #7F1D1D` | 负向指标 |
| Yellow | `#FEF3C7 → #78350F` | 温度、密度 |

### 发散色板 (Diverging)

| 名称 | 色带 | 适用场景 |
|------|------|---------|
| Blue-Red | `#3B82F6 → #F8FAFC → #EF4444` | 正负偏差 |
| Green-Red | `#10B981 → #F8FAFC → #EF4444` | 增减对比 |

### 分类色板 (Categorical)

| 名称 | 色值 | 适用场景 |
|------|------|---------|
| Standard | `#3B82F6 #10B981 #F59E0B #EF4444 #8B5CF6 #EC4899` | ≤6 类 |
| Extended | Standard + `#14B8A6 #F97316 #6366F1 #84CC16` | ≤10 类 |

### 热力色板

| 名称 | 色带 | 适用场景 |
|------|------|---------|
| Classic | `#0D0366 → #B93289 → #F58C6C → #FFFFF0` | 经典热力 |
| Ocean | `#0A1A3F → #1565C0 → #42A5F5 → #BBDEFB` | 海洋 |
| Magma | `#0D0366 → #7C3AED → #F97316 → #FBBF24` | 暗底热力 |

## 颜色无障碍

- 所有数据色板满足 WCAG 2.1 AA 级别对比度
- 分类色板适配色盲用户（不依赖红绿区分）
- 热力色板提供色阶数值标注
