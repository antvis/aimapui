# 蜂窝热力地图

蜂窝热力地图使用六边形网格聚合点数据，提供比经典热力更精确的区域统计。

## 推荐色板

| 级别 | 色值 | 透明度 |
|------|------|--------|
| 空 | `transparent` | 0 |
| 低 | `#0D1B3E` | 0.6 |
| 中 | `#1B4F8A` | 0.75 |
| 高 | `#3B82F6` | 0.85 |
| 极高 | `#FBBF24` | 0.9 |

## 尺寸规范

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 六边形覆盖率 | 0.85-0.95 | 防止间隙 |
| 3D 高度 | 0-60px | 按数据映射 |
| 描边 | 0.5px | 六边形边界 |

## Schema 示例


```tsx
{
  type: "hexagon",
  source: data, sourceType: "json",
  sizeField: "count", sizeValues: [0, 60],
  colorField: "count", colorValues: ["#0D1B3E", "#1B4F8A", "#3B82F6", "#FBBF24"],
  style: { coverage: 0.9, opacity: 0.85 }
}
```

## 视觉规则

- 颜色映射使用 5-7 级色带，避免过多分级造成视觉噪声
- 透明度默认 0.8，确保底图可读
- 悬停高亮色使用对比色或白色描边
- 文字标注需要描边（stroke）以保证可读性

## 暗色底图适配

暗色底图下需调整配色：
- 亮色方案中的浅色系替换为深色系
- 增加 opacity 提高数据层亮度
- 描边从深色改为浅色半透明
