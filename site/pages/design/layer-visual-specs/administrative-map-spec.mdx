# 行政区划地图

行政区划地图展示中国省市区三级行政边界，支持下钻交互和分级填充。

## 推荐色板

| 级别 | 边界色 | 边界宽 | 填充默认 |
|------|-------|--------|---------|
| 省级 | `rgba(255,255,255,0.5)` | 1.5px | 蓝色渐变 |
| 市级 | `rgba(255,255,255,0.3)` | 1px | 蓝色渐变 |
| 区县级 | `rgba(255,255,255,0.15)` | 0.5px | 蓝色渐变 |

## 尺寸规范

| 元素 | 参数 | 说明 |
|------|------|------|
| 悬停高亮 | 白色描边 2px | 区域选中 |
| 选中态 | 粗描边 + 提亮填充 | 点击下钻 |
| 过渡动画 | 300ms ease | 下钻过渡 |

## Schema 示例


```tsx
{
  type: "chinaDistrict",
  source: data, sourceType: "json",
  adCode: "100000", depth: 1,
  colorField: "value", colorValues: ["#DBEAFE", "#93C5FD", "#3B82F6", "#1D4ED8", "#1E3A8A"],
  style: { opacity: 0.8, stroke: "rgba(255,255,255,0.3)", strokeWidth: 1 },
  active: { color: "#F59E0B" }
}
```

## 视觉规则

- 颜色映射使用 5-7 级色带，避免过多分级造成视觉噪声
- 透明度默认 0.8，确保底图可读
- 悬停高亮色使用对比色或白色描边
- 文字标注需要描边（stroke）以保证可读性

## 暗色底图适配

暗色底图下需调整配色：
- 亮色方案中的浅色系替换为深色系
- 增加 opacity 提高数据层亮度
- 描边从深色改为浅色半透明
