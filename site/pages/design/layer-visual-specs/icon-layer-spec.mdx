# 图标标注规范

图标标注使用 IconFont 或图片在地图上标记 POI，需统一的尺寸、配色和层级规范。

## 推荐色板

| 用途 | 尺寸 | 配色 | 光晕 |
|------|------|------|------|
| 重要 POI | 24-28px | 语义色 | 4px 阴影 |
| 普通 POI | 16-20px | 语义色 | 2px 阴影 |
| 小 POI | 12-14px | 中性灰 | 无 |

### 语义配色

| 类型 | 颜色 | 说明 |
|------|------|------|
| 商业 | `#3B82F6` 蓝色 | 购物、办公 |
| 餐饮 | `#F59E0B` 橙色 | 餐厅、咖啡 |
| 医疗 | `#EF4444` 红色 | 医院、药店 |
| 教育 | `#8B5CF6` 紫色 | 学校、图书馆 |
| 交通 | `#10B981` 绿色 | 站点、停车场 |

## 尺寸规范

| 元素 | 参数 | 说明 |
|------|------|------|
| 图标尺寸 | 12-28px | 按重要性 |
| 图标颜色 | 语义色 | 按类型 |
| 光晕 | box-shadow | 提升可读 |
| 缩放适配 | 12-28px@z10-18 | 缩放级别 |

## Schema 示例


```tsx
{
  type: "iconFont",
  source: pois, sourceType: "json",
  iconField: "type",
  iconValues: { hospital: "\\ue601", school: "\\ue602", park: "\\ue603" },
  size: 20, color: "#3B82F6"
}
```

## 视觉规则

- 颜色映射使用 5-7 级色带，避免过多分级造成视觉噪声
- 透明度默认 0.8，确保底图可读
- 悬停高亮色使用对比色或白色描边
- 文字标注需要描边（stroke）以保证可读性

## 暗色底图适配

暗色底图下需调整配色：
- 亮色方案中的浅色系替换为深色系
- 增加 opacity 提高数据层亮度
- 描边从深色改为浅色半透明
