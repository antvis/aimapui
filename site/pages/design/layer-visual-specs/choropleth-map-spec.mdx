# 分级统计地图

分级统计地图（Choropleth）使用区域填充颜色编码数值，适用于行政区划数据分析。

## 推荐色板

| 分类 | 色板 | 适用场景 |
|------|------|---------|
| 顺序蓝 | `#DBEAFE → #1E3A8A` | GDP、人口 |
| 顺序绿 | `#D1FAE5 → #064E3B` | 正向指标 |
| 发散蓝红 | `#3B82F6 → #FFF → #EF4444` | 增长率偏差 |
| 分类 | `#3B82F6 #10B981 #F59E0B #EF4444` | 区域类型 |

## 尺寸规范

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 区域描边 | 0.5-1px | 区域边界 |
| 描边颜色 | `rgba(255,255,255,0.3)` | 亮色底图 |
| 描边颜色 | `rgba(255,255,255,0.1)` | 暗色底图 |
| 悬停描边 | 2px | 高亮边界 |

## Schema 示例


```tsx
{
  type: "polygon",
  source: regions, sourceType: "geojson",
  colorField: "value", colorValues: ["#DBEAFE", "#93C5FD", "#60A5FA", "#3B82F6", "#1D4ED8"],
  style: { opacity: 0.8, stroke: "rgba(255,255,255,0.3)", strokeWidth: 0.5 },
  active: { color: "#ffffff" }
}
```

## 视觉规则

- 颜色映射使用 5-7 级色带，避免过多分级造成视觉噪声
- 透明度默认 0.8，确保底图可读
- 悬停高亮色使用对比色或白色描边
- 文字标注需要描边（stroke）以保证可读性

## 暗色底图适配

暗色底图下需调整配色：
- 亮色方案中的浅色系替换为深色系
- 增加 opacity 提高数据层亮度
- 描边从深色改为浅色半透明
