# 路径轨迹地图

路径轨迹地图展示交通线路、物流轨迹等实际路径，沿路径线段展示方向和属性。

## 推荐色板

| 类型 | 色值 | 线宽 |
|------|------|------|
| 主干路 | `#3B82F6` | 3px |
| 分支路 | `#60A5FA` | 2px |
| 规划路 | `#93C5FD` | 1.5px dashed |
| 拥堵路段 | `#EF4444` | 3px |

## 尺寸规范

| 元素 | 参数 | 说明 |
|------|------|------|
| 路径线宽 | 1-5px | 按等级 |
| 箭头 | 沿路径 | 方向指示 |
| 动画 | 沿路径流动 | 可选 |
| 交汇点 | 圆形标记 | 节点 |

## Schema 示例


```tsx
{
  type: "line",
  source: routes, sourceType: "json",
  shape: "path",
  colorField: "level", colorValues: ["#3B82F6", "#60A5FA", "#F59E0B", "#EF4444"],
  sizeField: "level", sizeValues: [1, 4]
}
```

## 视觉规则

- 颜色映射使用 5-7 级色带，避免过多分级造成视觉噪声
- 透明度默认 0.8，确保底图可读
- 悬停高亮色使用对比色或白色描边
- 文字标注需要描边（stroke）以保证可读性

## 暗色底图适配

暗色底图下需调整配色：
- 亮色方案中的浅色系替换为深色系
- 增加 opacity 提高数据层亮度
- 描边从深色改为浅色半透明
