# 气泡地图

气泡地图使用圆的大小编码数值，配合颜色编码第二维度，适用于区域分级统计。

## 推荐色板

| 色级 | 色值 | 透明度 |
|------|------|--------|
| 1 (最低) | `#DBEAFE` | 0.7 |
| 2 | `#93C5FD` | 0.75 |
| 3 | `#60A5FA` | 0.8 |
| 4 | `#3B82F6` | 0.85 |
| 5 (最高) | `#1D4ED8` | 0.9 |

## 尺寸规范

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 最小气泡 | 8px | 最低值 |
| 最大气泡 | 50px | 最高值 |
| 描边 | 1px white | 气泡描边 |
| 悬停描边 | 2px | 高亮描边 |

## Schema 示例


```tsx
{
  type: "bubble",
  source: provinces, sourceType: "geojson",
  sizeField: "population", sizeValues: [8, 50],
  colorField: "gdp", colorValues: ["#DBEAFE", "#1D4ED8"],
  style: { opacity: 0.8, stroke: "#fff", strokeWidth: 1 },
  active: { color: "#F59E0B" }
}
```

## 视觉规则

- 颜色映射使用 5-7 级色带，避免过多分级造成视觉噪声
- 透明度默认 0.8，确保底图可读
- 悬停高亮色使用对比色或白色描边
- 文字标注需要描边（stroke）以保证可读性

## 暗色底图适配

暗色底图下需调整配色：
- 亮色方案中的浅色系替换为深色系
- 增加 opacity 提高数据层亮度
- 描边从深色改为浅色半透明
