# 弧线流向地图

弧线流向地图展示地理空间中的 OD（Origin-Destination）关系，通过弧线动画体现流量方向与规模。

## 推荐色板

| 类型 | 色值 | 线宽 |
|------|------|------|
| 低流量 | `#93C5FD` | 1px |
| 中流量 | `#3B82F6` | 2px |
| 高流量 | `#1D4ED8` | 3px |
| 热门线路 | `#FBBF24` | 3px + glow |

## 尺寸规范

| 元素 | 参数 | 说明 |
|------|------|------|
| 弧线高度 | arcHeight: 0.3-0.8 | 根据距离调整 |
| 动画周期 | duration: 3-6s | 流速感 |
| 拖尾长度 | trailLength: 1-3 | 流动感 |
| 透明度 | opacity: 0.6-0.9 | 避免遮挡 |

## Schema 示例


```tsx
{
  type: "arcFlow",
  source: flows, sourceType: "json",
  sourceConfig: { x: "fromLng", y: "fromLat", x1: "toLng", y1: "toLat" },
  colorField: "volume", colorValues: ["#93C5FD", "#3B82F6", "#1D4ED8"],
  sizeField: "volume", sizeValues: [1, 3],
  animate: { enable: true, duration: 4, trailLength: 2 },
  style: { arcHeight: 0.5, opacity: 0.8 }
}
```

## 视觉规则

- 颜色映射使用 5-7 级色带，避免过多分级造成视觉噪声
- 透明度默认 0.8，确保底图可读
- 悬停高亮色使用对比色或白色描边
- 文字标注需要描边（stroke）以保证可读性

## 暗色底图适配

暗色底图下需调整配色：
- 亮色方案中的浅色系替换为深色系
- 增加 opacity 提高数据层亮度
- 描边从深色改为浅色半透明
