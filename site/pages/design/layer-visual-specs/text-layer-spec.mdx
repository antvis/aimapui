# 文字标注规范

文字标注在地图上为地理要素提供名称和属性信息，需保证可读性和层次感。

## 推荐色板

| 用途 | 字号 | 字重 | 颜色 | 描边 |
|------|------|------|------|------|
| 城市名 | 14-16px | 600 | `#0F172A` | 2px white |
| 区域名 | 12-14px | 500 | `#334155` | 1.5px white |
| POI 名 | 10-12px | 400 | `#475569` | 1px white |
| 数值标注 | 10px | 400 | 随图层色 | 1px white |

## 尺寸规范

| 元素 | 参数 | 说明 |
|------|------|------|
| 描边色 | 底图互补色 | 保证可读 |
| 描边宽 | 1-2px | 按字号 |
| 允许重叠 | 默认 false | 密集区域开启 |
| 避让优先级 | 按数据值排序 | 大值优先 |

## Schema 示例


```tsx
{
  type: "point",
  source: labels, sourceType: "json",
  sourceConfig: { x: "lng", y: "lat" },
  shapeField: "name", shapeValues: "text",
  size: 12, color: "#0F172A",
  style: { stroke: "#FFFFFF", strokeWidth: 2, textAllowOverlap: false }
}
```

## 视觉规则

- 颜色映射使用 5-7 级色带，避免过多分级造成视觉噪声
- 透明度默认 0.8，确保底图可读
- 悬停高亮色使用对比色或白色描边
- 文字标注需要描边（stroke）以保证可读性

## 暗色底图适配

暗色底图下需调整配色：
- 亮色方案中的浅色系替换为深色系
- 增加 opacity 提高数据层亮度
- 描边从深色改为浅色半透明
