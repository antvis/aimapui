# 沉浸式旅行规范

沉浸式旅行地图强调沉浸感和叙事性，通过 3D 视角、动画和视觉焦点引导用户体验。

## 布局模式

### 沉浸式全屏

```
┌──────────────────────────────────┐
│                                  │  ← 3D 倾斜视角 (pitch: 45-60°)
│         地图全屏                  │
│         路线动画                  │
│                                  │
│  ┌────────────────────────┐      │
│  │ 目的地名称              │      │  ← 浮层信息卡
│  │ 距离: xxx  时间: xxx    │      │
│  │ [开始导航]              │      │
│  └────────────────────────┘      │
│                                  │
└──────────────────────────────────┘
```

## 3D 视角配置

```tsx
const immersiveMap = {
  map: {
    basemap: 'gaode',
    style: 'dark',
    pitch: 50,         // 倾斜 50°
    rotation: -15,     // 轻微旋转
    zoom: 14
  }
}
```

## 动画规范

| 动画 | 说明 | 时长 |
|------|------|------|
| 飞行到点 | 相机平滑移动 | 2-3s |
| 旋转环绕 | 360° 旋转展示 | 10-15s |
| 路径描画 | 路线逐步绘制 | 3-5s |
| 点位脉冲 | 目的地标注脉冲 | 2s 循环 |

## 信息卡片

| 元素 | 规格 |
|------|------|
| 位置 | 底部 1/4 区域 |
| 背景毛玻璃 | `rgba(0,0,0,0.6)` + `blur(20px)` |
| 圆角 | `16px 16px 0 0` |
| 标题字号 | 20px / 700 |
| 正文字号 | 14px / 400 |
| 按钮高度 | 44px |

## 视觉焦点引导

1. **3D 建筑**：目的地建筑 3D 挤出 + 高亮
2. **路线飞线**：出发地到目的地的弧线动画
3. **目标脉冲**：目的地点位持续脉冲
4. **渐显标注**：周边 POI 缩放时渐显

## 适配

| 设备 | 调整 |
|------|------|
| Desktop | 完整 3D + 飞线 + 面板 |
| Tablet | pitch 降低至 30°，面板缩小 |
| Mobile | 2D 俯视，BottomSheet 替代面板 |
