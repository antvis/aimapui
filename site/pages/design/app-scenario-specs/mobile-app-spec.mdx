# 移动端应用规范

移动端地图应用需精简 UI、优化触摸交互、适配小屏幕。

## 布局模式

### 全屏地图 + BottomSheet

```
┌──────────────────────┐
│ [搜索]        [定位]  │
│                       │
│                       │
│                       │
├──────────────────────┤  ← BottomSheet (可拖拽)
│ POI 详情              │
│ 地址: xxx             │
│ [导航] [收藏]         │
└──────────────────────┘
│  [图层]  [缩放+-]     │
└──────────────────────┘
```

### 列表+地图分屏

```
┌──────────────────────┐
│                       │
│  列表区域 (50%)       │
│  - POI 1             │
│  - POI 2             │
├──────────────────────┤
│  地图区域 (50%)       │
│                       │
└──────────────────────┘
```

## 控件精简

移动端只保留核心控件：

| 保留 | 移除/替换 |
|------|----------|
| 定位按钮 | 鼠标坐标 |
| 缩放按钮 | 全屏按钮（移动端始终全屏） |
| BottomSheet 图例 | 浮动图例 |
| 搜索栏 | - |

## 触摸区域

| 元素 | 最小触摸区域 |
|------|------------|
| 按钮 | 44px × 44px |
| 列表项 | 48px 高 |
| 搜索栏 | 44px 高 |
| BottomSheet 拖拽条 | 48px 高 |

## 安全区适配

```css
.safe-area-bottom {
  padding-bottom: env(safe-area-inset-bottom);
}
.safe-area-top {
  padding-top: env(safe-area-inset-top);
}
```

## BottomSheet 规范

| 状态 | 高度 |
|------|------|
| 收起 | 0px |
| 半屏 | 40vh |
| 全屏 | 90vh |
| 拖拽手柄 | 32px × 4px |
