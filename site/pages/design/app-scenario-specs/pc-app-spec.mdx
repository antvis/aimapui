# PC 端应用规范

PC 端地图应用通常有大屏优势，可以同时展示多个面板和控件。

## 布局模式

### 全屏地图

```
┌─────────────────────────────────────────┐
│ [搜索]                    [主题][全屏]   │
│                                         │
│                                         │
│                                         │
│                                         │
│  [图例]                    [Zoom +-]    │
│  [比例尺]                               │
└─────────────────────────────────────────┘
```

### 左侧面板

```
┌──────────┬──────────────────────────────┐
│ 搜索栏    │                              │
│ 图层切换  │                              │
│ 筛选面板  │          地图区域             │
│ 数据统计  │                              │
│          │              [Zoom] [图例]    │
│          │              [比例尺]         │
└──────────┴──────────────────────────────┘
```
面板宽度：320px (固定) 或 25% (弹性)

### 右侧面板

```
┌──────────────────────────────┬──────────┐
│                              │ 详情面板  │
│                              │ 数据表格  │
│          地图区域             │ 统计图表  │
│                              │          │
│ [搜索] [Zoom]                │          │
│ [图例] [比例尺]              │          │
└──────────────────────────────┴──────────┘
```

## 控件布局

| 位置 | 控件 |
|------|------|
| Top-left | 搜索栏 |
| Top-right | 主题切换、全屏、导出 |
| Bottom-left | 比例尺、鼠标坐标 |
| Bottom-right | 缩放控件、图例 |

## 尺寸规范

| 元素 | 尺寸 |
|------|------|
| 侧边面板 | 320px / 25% |
| 搜索栏 | 400px × 40px |
| 控件按钮 | 36px × 36px |
| 图例面板 | 180-240px × auto |
| 底图留白 | 16px |
