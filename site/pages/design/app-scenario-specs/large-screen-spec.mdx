# 大屏可视化规范

大屏展示场景（指挥中心、数据看板）强调视觉冲击力和信息密度。

## 布局模式

### 指挥中心大屏

```
┌────────┬──────────────────────────┬────────┐
│  统计  │                          │  排行  │
│  面板  │       地图主区域          │  面板  │
│  200px │                          │  200px │
│        │                          │        │
├────────┤                          ├────────┤
│  图例  │                          │  时间  │
│        │                          │  轴    │
└────────┴──────────────────────────┴────────┘
```

### 数据看板

```
┌──────────────────────────────────────┐
│  标题栏 + 时间选择  + 全屏           │
├──────────────────────────────────────┤
│              地图区域                 │
│              (60vh)                  │
├──────────┬───────────┬──────────────┤
│ 统计卡片1 │ 统计卡片2  │ 统计卡片3    │
└──────────┴───────────┴──────────────┘
```

## 视觉特性

| 特性 | 规范 |
|------|------|
| 底图 | 暗色底图 (`dark`) |
| 主色调 | 蓝色/青色系 |
| 文字 | 白色/浅灰 |
| 面板 | 深色半透明 + 发光边框 |
| 动画 | 流线、脉冲、粒子 |

## 暗色面板样式

```css
.large-screen-panel {
  background: rgba(6, 18, 42, 0.85);
  border: 1px solid rgba(59, 130, 246, 0.3);
  border-radius: 4px;
  box-shadow: 0 0 20px rgba(59, 130, 246, 0.1);
  color: #E2E8F0;
}
```

## 字体规范

| 用途 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 大屏标题 | 24-32px | 700 | `#F8FAFC` |
| 面板标题 | 16-18px | 600 | `#E2E8F0` |
| 数据标注 | 28-48px | 700 | `#60A5FA` |
| 正文 | 14px | 400 | `#94A3B8` |
| 辅助文字 | 12px | 400 | `#64748B` |

## 动效规范

| 动效 | 说明 | 参数 |
|------|------|------|
| 飞线 | OD 流动 | duration: 4-6s, trailLength: 2 |
| 脉冲 | 中心点扩散 | 2s 循环 |
| 数字跳动 | 数据更新 | 1s 缓动 |
| 面板滑入 | 初始加载 | 0.5s ease-out |
