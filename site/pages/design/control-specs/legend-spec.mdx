# 图例规范

aimapui 提供 8 种图例类型，每种图例遵循统一的视觉和交互规范。

## 通用规范

### 图例容器

```css
.legend {
  background: rgba(255, 255, 255, 0.72);
  backdrop-filter: blur(12px);
  border-radius: 8px;
  padding: 12px;
  font-size: 12px;
  color: #0F172A;
  min-width: 160px;
  max-width: 240px;
}
```

### 标题

- 字号 13px，字重 600
- 与图例内容间距 8px
- 可选关闭按钮

## 图例类型

### CategoriesLegend（分类图例）

| 元素 | 规范 |
|------|------|
| 色标 | 12x12px 圆形 |
| 标签 | 12px，与色标间距 6px |
| 行间距 | 4px |
| 交互 | 点击切换显隐 |

### RampLegend（渐变色带）

| 元素 | 规范 |
|------|------|
| 色带 | 宽度 180px，高度 12px，圆角 6px |
| 标签 | 12px，色带下方 |
| 刻度 | 最小值/最大值 |

### DivergingLegend（发散色带）

| 元素 | 规范 |
|------|------|
| 色带 | 宽度 180px，高度 12px |
| 中点标记 | 0 值标注 |
| 标签 | 最小/0/最大 |

### ThresholdLegend（阈值图例）

| 元素 | 规范 |
|------|------|
| 色块 | 每段独立色块 |
| 断点 | 阈值数字标注 |
| 最小宽度 | 每段 20px |

### SizeLegend（尺寸图例）

| 元素 | 规范 |
|------|------|
| 图形 | 渐变大小圆形 (最小→最大) |
| 标注 | 最小值和最大值 |
| 排列 | 水平嵌套或垂直递增 |

### LineWidthLegend（线宽图例）

| 元素 | 规范 |
|------|------|
| 线段 | 渐变宽度 (1px→max) |
| 颜色 | 跟随图层色 |
| 标注 | 最小/最大线宽 |

### ProportionLegend（比例图例）

| 元素 | 规范 |
|------|------|
| 排列 | 水平堆叠条 |
| 色段 | 各分项颜色 |
| 标签 | 分项名称 + 百分比 |

### IconLegend（图标图例）

| 元素 | 规范 |
|------|------|
| 图标 | 16x16px |
| 标签 | 12px，与图标间距 6px |
| 行间距 | 4px |

## 交互

| 交互 | 行为 |
|------|------|
| 悬停图例项 | 高亮对应数据 |
| 点击图例项 | 切换对应分类显隐 |
| 拖拽图例 | 移动图例位置（需 `draggable: true`） |

## 暗色模式

```css
.dark .legend {
  background: rgba(15, 23, 42, 0.72);
  color: #F8FAFC;
}
```
